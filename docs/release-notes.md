# 超昂大战 · 角色个人剧情离线阅读器 v{VERSION}

把《超昂大战》的角色个人剧情做成可离线翻阅的阅读器：还原原作演出
（背景 / 立绘 / CG / 语音 / BGM），支持导入中文译文，可导出视频与 CG。

## 下载哪个

| 文件 | 说明 |
|---|---|
| `ESCAH-Offline-v{VERSION}-win64-portable.zip` | **给普通用户**。内置 Python 3.11 与全部依赖，解压后双击 `启动.bat` 即用 |
| `ESCAH-Offline-v{VERSION}-update.zip` | **程序更新时会自动下载安装这个包**，只有代码与文档 |

## 第一次用

1. 解压 portable 包到一个**路径里没有中文和空格**的目录，双击 `启动.bat`
2. 打开「资源管理」页 → 下载**基础数据**（资源清单 + 公共素材）
3. 再到「剧情安装」勾想看的角色，点「开始安装」
4. 装完回「角色剧情」页，点角色就能播

## 注意

- **本包不含任何游戏素材**，需按上述步骤自行从官方 CDN 下载并在本机解包
