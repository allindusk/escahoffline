这个选项是什么意思？一般不用改

一部剧情不是一个大文件，而是几十个小文件（剧本、语音、图片分开打包）。程序可以同时下好几个，所以这里选的是同时下几个。

数字越大越快：默认 32 最快最省时间。如果经常看到失败、或者网络本来就慢，就往小调（16 → 8），稳一点。

技术细节：高清图存在 media/img_x2/，并登记在 data/imgmap.x2.js 里。引擎是 Real-CUGAN （realcugan-ncnn-vulkan，参数 -m models-se -n 2 -s 2），默认放在 tools/realcugan/。没有这个引擎就不能超分。

  • 从别的电脑、或者自己的备份里拷了高清图过来，程序还不知道有这些图；
  • 上次超分中途强退过（断电、任务管理器结束进程），有的图做了却没记上；
  • 「设置 / 清理空间」里明明有一堆高清图占着空间，播放器里看到的却还是原来的糊图。

点一下只要 …：它只是把硬盘上已经做好的高清图数一遍、重新登记给播放器。 不会重新超分、不会改动或删除任何图片，硬盘占用一点都不会变。

更新是从哪下的？（技术细节，不看也不影响使用）

剧情目录走官方服务器；角色资料走 GitHub 上的每日自动更新，有几条备用线路，哪条通就用哪条（和「检查程序更新」共用同一张线路表）。只有全部线路都不通时，才会退回直连 Wiki —— 那个站在日本，才需要代理。角色资料更新失败不影响剧情目录。

程序本体的下载顺序：gh-proxy 主站 → 优选 v4 → 优选 v4/v6 → Fastly，哪条有响应就用哪条（不测速）；四条都不通才用 GitHub 官方直连。

剧情本身不能删：剧本、图片、语音是你装好的剧情本体，删了就得重装。所以下面的清理项都不动它们。

帮助

这个项目是什么

把《超昂大战》的角色个人剧情做成能离线翻阅的阅读器：还原原作演出（背景 / 立绘 / CG / 语音 / 音乐），可以导入中文译文，也能导出视频和 CG。

程序是开源的，游戏素材不在里面 —— 第一次用要去「剧情安装」页 自己下载。中文译文也不附带，需要自己翻或用 AI 翻了导进来。

三步上手

  1. 下基础数据：左边「① 概览 / 快速开始」点「下载基础数据」。背景和音乐所有剧情共用，一次下齐最省事。
  2. 装一部剧情：「② 剧情安装」→ 勾想看的角色或章节 → 点「开始安装」。
  3. 开始看：回「角色剧情」→ 左边点角色就播。想要中文，点播放器里的「翻译」。

几个容易找不到的地方

功能都在，只是位置不显眼 —— 这里一次说清。

想跳到剧情中间某一段

播放器底下那条进度条可以直接点，点哪儿就跳到哪儿。正在播就接着播； 已经暂停的话只跳过去、不会自己播（等你看清楚再点播放）。

快捷键记不住

播放器底下最右边那个「?」点一下，所有快捷键就列出来了（空格暂停、回车下一句、按住 K 快进、F 全屏…），点别处或按 Esc 收起。

左边列表太占地方

列表顶上点「收起」，或者按键盘上的 [，只留画面；再点一次就展开。

「其他」里的剧情怎么是一组一组的

「其他」按游戏里的入口分好了组：打 BOSS、広域戦、殲滅戦、周年庆、愚人节、H 场景合集…一共 17 组。点组名就展开，里面的名字跟游戏里一模一样（来襲 その1、忍者 3、祝！3.5周年！！…）。

想先看看「变高清」到底能清楚多少

「③ 提高CG画质」页右上角有个「查看效果」：左边是原来的样子，右边是变清楚之后的样子，中间那条竖线可以拖着比，还能全屏看。觉得不值就关掉，不会动你的任何文件。

高清图做完了，画面却没变清楚

去「③ 提高CG画质」页最下面那个折叠项「高清图做了，画面却没变清楚？」，点一次里面的「重新登记高清图」（…）。它只是把已经做好的高清图重新数一遍、登记给播放器，不会重新超分、也不动任何图片。一般是把文件从别处拷过来、或者上次超分中途强退过，才需要这么修一下。

CG 页怎么只有角色的图，剧情的图在哪

CG 页搜索框下面有一排小按钮：角色 / 主线 / 活动 / 其他，点一下就换一类。换到剧情那几类以后，左边列的是「哪一部剧情」；右上角的「⬇ 导出 CG」也能把这一批打包下来。

想让手机 / 另一台电脑也能看

播放器右上角有 「局域网二维码」，点一下会出一个二维码：手机连同一个 WiFi 扫一下就能看；另一台电脑把弹出来的那行地址输进浏览器也行。扫不开的话，多半是电脑的安全软件把外面连进来的请求挡住了 ——启动时那个黑窗口里有一行提示，照着做一次就好。

想批量翻译，怎么一次挑出没翻过的

「⑤ 翻译」页那排按钮里点「全选未翻译」（可以先把列表缩到你要的那一类），再点这一行最右边的「导出所选剧情」。翻好之后用上面的「批量导入」放回来。

常见问题

点角色提示"资源还没有下载"

这部剧还没装。回「剧情安装」，勾上它（可以按名字搜），点「开始安装」。装好之后它会自动出现在播放器里。

有画面但没声音 / 没有背景音乐

先看「基础数据」里的公共素材下过没有：背景、音乐、音效、头像、剧情横幅都是所有剧情共用的， 不下就只有你装过的那几部剧情自带的东西（侧栏没头像、剧情列表没标题横幅）。如果下过了还是没声音，用鼠标点一下画面再播（浏览器会拦自动播放）。

立绘缺脸 / 显示不完整

约一成的特殊立绘，在游戏原作里本身就是分开画的（缺了脸部那一层）。播放器设置里勾上「显示不完整立绘」就能看到底图。

下载到 100% 了却一直在转

正常。下完还要在原地「拆开装好」，这一步在进度条上接着往后走， 不是卡住了，等它走完就行。真的一动不动，就点一下「暂停」再「继续」。

下载很慢

把「剧情安装」页的下载速度调大（32 最省时间）；老是失败就调小到 8–16。另外下载前先关掉代理软件——代理按流量计费，一部剧情 …。

磁盘满了 / 想清理空间

去「设置 / 清理空间」页，那里把占地方的东西按用途列全了，还会告诉你哪些删了不影响看：下载时留下的临时文件、没用的旧缓存、 已经被高清版替换掉的原图、导出的成品、日志。只想删某一部剧情，就在「剧情安装」里点那一行的「卸载」。

想让新手引导再讲一遍

点页面右上角的 「?」（播放器里按 H 也行），引导会从头再放一次。这个「帮助」页往下就是常见问题，遇到怪现象先来这里翻一翻。
