# 超昂大战 · 角色个人剧情离线阅读器 v{VERSION}

把《超昂大战》的角色个人剧情做成可离线翻阅的阅读器：还原原作演出
（背景 / 立绘 / CG / 语音 / BGM），支持导入中文译文，可导出视频与 CG。

> 替换成实际版本号；更早的版本留在下面即可（不会自动替换）。
> 这里只写「修了什么 / 加了什么」，方便用户点「检查程序更新」时直接看到。

### v{VERSION}（2026-11-01）
- **修复：剧情译文不加载（一直显示原文）**
  播放器探测「有没有译文」时请求了错误的路径 `assets/i18n/zh-Hans/index.json`
  （该文件实际不存在），导致判定为「没有译文」，于是逐条 `char_<id>.json`
  永远不被加载。改为请求正确的顶层清单 `assets/i18n/index.json` 后，
  译文恢复按角色懒加载。
  **属于程序 bug，升级后自动修复，无需重新下载译文。**

## 第一次用

1. 解压 portable 包到一个**路径里没有中文和空格**的目录，双击 `启动.bat`
2. 打开「资源管理」页 → 下载**基础数据**（资源清单 + 公共素材）
3. 再到「剧情安装」勾想看的角色，点「开始安装」
4. 装完回「角色剧情」页，点角色就能播
