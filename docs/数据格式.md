# 数据格式

> 想把播放器接到别的游戏/别的剧情来源，改这一层就够了：**只要产物是这里的结构，
> 播放器照常工作**。所以本文件也是"换数据源"的接口说明。

所有数据文件都是 `window.__X = {...};` 形式的**纯数据脚本**（不是 JSON，
避免 `file://` 下的 CORS 问题）。解析方式统一是：取第一个 `=` 之后、去掉结尾 `;`、`JSON.parse`。

---

## 1. 索引层（`web/data/`，进 Git）

### `names.js` → `window.__NAMES`
```js
{ "1": "神騎プラチネル", "79": "ルカ", … }   // 角色 id → 日文名
```

### `charmeta.js` → `window.__CHARMETA`
```js
{ "79": { "r": "SSR", "d": "2023-05-01" }, … }
// r 稀有度 SSR|SR|R / d 实装日期（排序用，可空）
// **不含中文名**：这是随包分发的出厂索引，带 zh 会让全新安装的 CG 页/侧栏
// 直接显示中文（全量包必须纯日文）。
```

中文名的唯一来源是用户目录里的 `userdata/char_meta.json`（键=日文名，值里可写
`zh`）。首启会从 `server/cdn/data/char_meta.json` 种一份**不含 zh/icon** 的模板
过去；想导出 `魔女伊蕾娜_p1.mp4` 这种文件名就自己补 zh 列。没有 zh 时
`server/names.py` 退回日文名，再退回 `角色<id>`。

### `index.js` → `window.__INDEX`
```js
[ { "id": 79, "parts": 6, "lines": 812 }, … ]
// 侧栏角色列表的数据源；lines 用于显示"多少句"
```

### `advindex.js` → `window.__ADV`
```js
[ { "key": "adv_main_40", "kind": "main", "no": 40, "cover": "media/img/story/main_40.webp",
    "first": "第一句台词（搜索用）", "parts": 3, "lines": 420, "voices": 380, "voiceRes": 380 } ]
// kind: main | event | other | side | tutorial | op
```

### `imgmap.js` → `window.__IMGMAP`
```js
{ "stand": { "<图片键>": "media/img/stand/<键>.webp" },
  "back":  { … }, "cg": { … } }
```
- **值一定是「原图」路径**（`media/img/…`），不是超分图
- 生成脚本：`tools/build_imgmaps.py`（可重复运行）
- 不要在运行时改它 → 用户态改动写在覆盖层里（见下）

### `imgmap.x2.js` → `window.__IMGX2`
同结构，值是 `media/img_x2/…`（超分图）。**可以缺**，缺了等于没超分。

### `imgmap.base.js` → `window.__IMGBASE`
同结构，值是 WebP 转码后的新路径。**可以缺**。

> 取图顺序（`player.js` 的 `candsOf`）：
> `__IMGX2`（且用户开了"优先超分"）→ `__IMGBASE` → `__IMGMAP`，
> `<img onerror>` 逐级回退。三层都没有才隐藏。

### `sfxmap.js` → `window.__SFX`
```js
{ "<音频键>": "media/audio/bgm/xxx.m4a", … }
```

### `cgmap.js` → `window.__CGMAP`
```js
[ { "c": 1, "k": "イベ_1_神騎プラチネル", "f": ["xxx.jpg", …],
    "n": 6, "p": 5, "g": "神騎プラチネル" } ]
// c 角色 id / k 组名 / f 该组图片文件名列表（文件名即 imgmap.cg 的键去掉扩展名）
// n 张数 / p 起始分段 / g 组标签（純愛·陵辱，或英雄名·素颜名；无标签为空）
// 组 = 「同一批 CG」：CG 名里的号（0396 / 396）和剧本标签一样才算同一批。
// 角色页只收自己名下的图（`イベ_<角色号>_…`）；联动别人的图、以及不带号的
// 美术字宣传图（`イベ_狂王` 这类 2048×1152）不进角色页，它们在 −1/−2/−3 桶里。
// 生成器：tools/build_cgmap.py（--apply 写文件）。384 个角色恒为 2 组。
// 出厂内容是打包快照；装完某部剧情后 stages.sync_cgmap(cid) 会把该剧本引用、
// 但表里还没有的组增量合并进来（只加不删、幂等）——否则官方上新角色后，
// CG 页永远看不到新图，只能等下一次发版。
```

### `packs.json`
> **已移除。** 早期那套「自建 zip 资源源」的清单文件已随流程删除，
> 现在剧情清单由官方 CDN 的 Manifest1Ex / 2Ex 直接提供（见 `资源包与发布.md`）。

### `app.json`
```js
{ "repo": "owner/name", "name": "ESCAH-Offline", "channel": "stable", "docs": "docs/AI-ONBOARDING.md" }
```

## 2. 剧情层（`web/data/char_<id>.js` / `adv_<kind>_<no>.js`，不进 Git）

角色剧情：`window.__CHAR`；主线/活动：`window.__STORY`。两者**结构完全同构**：

```js
{
  "id": 79,                 // 角色的数字 id（adv 里可省略）
  "no": 40,                 // adv 的章节号（char 里没有）
  "parts": [
    {
      "file": "adv_char_79_0",       // 原资源名，仅作标识
      "stand": ["stand_79_…"],       // 本段用到的立绘键（用于资源分析）
      "full":  ["79"],               // 全身立绘键（= 角色 id）
      "back":  ["94778C69_…"],       // 背景键
      "cg":    ["83438378_…"],       // CG 键
      "music": ["89B98A79_…"],       // BGM 键
      "sound": ["8CF889CA89B9_…"],   // 音效键
      "voices": ["00005_7155", …],   // 语音文件名（不含扩展名）
      "methods": [ … ]               // ★ 演出指令序列
    }, …
  ]
}
```

`stand / back / cg / music / sound / voices` 这几个清单**不是渲染用的**，而是给
`tools/build_packs.py` 做引用分析用的——有它们才能算出"这部剧情需要哪些文件"。
新数据源请务必填全，否则资源包会漏文件。

## 3. 演出指令（`parts[].methods[]`）

时序模型（与 Unity 协程一致）：

- 画面/文字/语音类指令**立即启动、不阻塞**，动画 Promise 累积到 `ST.pendingAll`
- `WaitMotion` 是同步点：等待本轮累积的动作全部完成
- `Wait` 是显式停顿

| Method | 关键字段 | 语义 |
|---|---|---|
| `ShowBackground` | `BackImage` | 切换背景 |
| `HideBackground` | — | 清空背景 |
| `ShowDoubleBackground` / `ShowDoubleBackgroundOffset` | `BackImage` `BackImage2` `…` | 左右双背景 |
| `MulColorBackground` | `Color` `Alpha` | 背景染色 |
| `ShowStand` / `ShowStandAndSit` | `StandImage` `Position`(Left/Center/Right/All) `Motion` `GroupId` `Z` `Time` | 显示立绘 |
| `HideStand` | `Position`（`All` = 清空全场）`Motion` `Time` | 隐藏立绘 |
| `MotionStand` | `Motion`(`ポップ`/`移動`/`横揺れ`/`おじぎ`/`微動`/`振動`/`右突き`/`左突き`/`左ポップ`) | 立绘动作 |
| `MoveStand` / `SwapStand` / `MulStand` / `ShakeStand` | 位置/颜色/幅度 | 立绘变换 |
| `ShowEventCg` | `EventImage` `Time` | 显示 CG |
| `HideEventCg` | `Time` | 隐藏 CG |
| `ZoomInEventCG` / `FastZoomInEventCG` / `ZoomOutEventCG` / `StareEventCG` / `EndStareEventCG` | — | CG 镜头效果 |
| `ShowMessageWindow` / `HideMessageWindow` | — | 对话框显隐 |
| `ShowMessage` | `Name` `Message` `Type`(`Talk`/…) `Time` `VoiceMark` | ★ 台词（打字机效果） |
| `VOICE` | `Voice` | 播放语音 |
| `PlayMusic` / `StopMusic` | `Music` | BGM |
| `PlaySound` / `PlayLoopSound` / `StopLoopSound` | `Sound` | 音效 |
| `WaitMotion` | — | 等待本轮所有动画 |
| `Wait` | `Time` | 显式停顿（秒） |
| `Shake` / `ScreenFlash` / `ScreenFlashIn` / `ScreenFlashOut` | 强度/时间 | 全屏效果 |
| `SetDrawModeSepia` / `SetDrawModeGrayscale` / `SetDrawModeDefault` | — | 画面滤镜 |
| `ShowPlace` / `ShowStandEffect` / `ShowScreenEffect(Back)` | `Place`/`Effect` | 场景名与图层特效 |
| `ToUpper` / `ToLower` | — | 台词字号放大（喊话） |
| `TalkCharacter` / `ClearTalkCharacter` | — | 高亮当前说话人（当前实现为空操作） |

> 数据里存在**同义不同名**的指令（如 `ShowMessage` 与 `Talk`），`player.js` 里做了兼容。
> 新增分支时别只认一种写法。

## 4. 译文层（`web/assets/i18n/`）

```
web/assets/i18n/
├─ index.json                  { "chars": { "79": { "zh-Hans": 812 } } }
├─ ui.json                     界面文案（data-i18n 属性用）
└─ zh-Hans/
   ├─ char_79.json             { "unit":"char_79", "lang":"zh-Hans",
   │                             "updated":"…", "messages": { "日文原文": "中文" } }
   └─ adv_main_40.json
```

- **key 永远是日文原文整句**（含标点，空格敏感）
- `messages` 必须是子字典（v2 起禁用 `### ` 块头格式）
- 导入导出格式见 [翻译指南.md](翻译指南.md)

## 5. 运行时状态（`userdata/`，不进 Git）

| 文件 | 内容 |
|---|---|
| `config.json` | 下载线程、超分开关、WebP 质量、端口等（`server/paths.py` 的 `DEFAULTS`） |
| `state.json` | 已安装的包、文件/字节统计、超分记录、当前版本 |
| `links.json` | 明文下载源（优先级最高，写法同 `packs.links.js` 解密后的内容） |
| `downloads/` | 下载中的 `.part` 与 `.part.json`（断点续传状态） |
| `backup/` | 预留：超分前原图备份（当前策略是"不覆盖原图"，所以通常为空） |
| `export/` | 导出的视频 / CG 压缩包 |
| `logs/errors.log` | 任务异常堆栈 |
| `update/` | 更新暂存区与更新器脚本 |
