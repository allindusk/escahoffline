这个选项是什么意思？一般不用改

一部剧情不是一个大文件，而是几十个小文件（剧本、语音、图片分开打包）。 程序可以同时下好几个，所以这里选的是同时下几个。

数字越大越快：默认 32 最快最省时间。 如果经常看到失败、或者网络本来就慢，就往小调（16 → 8），稳一点。

勾一部剧情就会带上它需要的全部资源包； 「缺语音」「不完整」的也能勾，勾上再点安装就是补齐（只下缺的，不用重装）

⚠ 超分很吃电脑，请先想清楚要不要开：
  • 很耗时：一部剧情通常几十到一百多张图，要 1–3 分钟（比下载还久）。
  • 占 CPU：跑的时候电脑会变卡、风扇会响，笔记本掉电也会快一点。
  • 占硬盘：高清图是额外一套，约占原图 1–2 倍空间。
  • 随时能取消：已经做完的不会白做，下次接着来；关掉页面也不影响。

建议：第一次先不勾，装上剧情看看画面够不够清楚。 觉得糊再来本页单独做一次。超分不是装剧情的必要条件。

想反悔怎么办？能撤掉吗？

原图一直在，没被动过。不想要高清图了，到 「设置 / 清理空间 → 超分高清图」删掉就行，删完还是照样播（画质变回原图）。

反过来，如果觉得高清版够好、想省点空间，可以把 已经有高清版的那些原图删掉 —— 播放时会用高清版，不影响观看。

技术细节：高清图存在 media/img_x2/，并登记在 data/imgmap.x2.js 里。引擎是 Real-CUGAN （realcugan-ncnn-vulkan，参数 -m models-se -n 2 -s 2）， 默认放在 tools/realcugan/。没有这个引擎就不能超分。

图片格式（自动处理，不用管）

下载下来的图片会自动压成更小体积的格式，画质几乎看不出差别， 但硬盘能省下三到四成。这一步没有开关，也不需要你设置。

① 更新剧情目录（有新剧情时点一次）

点一下，程序会去问官方"有没有新剧情"，大约 10–20 秒。 顺便把角色的稀有度、实装日期也刷新一遍。 如果公共素材（背景 / 音乐 / 音效）有更新，会自动补下，不用你管。

连不上服务器（剧情目录已更新，角色资料没更新）。 请检查网络，或开一下代理再点「补下载」。

② 更新程序本体

点「检查程序更新」看有没有新版；有新版本再点右边那个按钮， 程序会自己换好文件并重启。发现有新版时，下面会列出本次更新修了什么。整个过程中 你的素材、译文、设置一个都不会丢。

默认勾选：启动后只查一次有没有新版，有就在页面顶部提示一句 （不会自动下载、不会自动重启）。不想让它联网就取消勾选。
更新是从哪下的？（技术细节，不看也不影响使用）

剧情目录走官方服务器；角色资料走 GitHub 上的每日自动更新， 有几条备用线路，哪条通就用哪条（和「检查程序更新」共用同一张线路表）。 只有全部线路都不通时，才会退回直连 Wiki —— 那个站在日本，才需要代理。 角色资料更新失败不影响剧情目录。

程序本体的下载顺序：gh-proxy 主站 → 优选 v4 → 优选 v4/v6 → Fastly， 哪条有响应就用哪条（不测速）；四条都不通才用 GitHub 官方直连。

容量占用

点一下重新算（约 1–3 秒）
这些东西分别是什么？哪些能删？

剧情本身不能删：剧本、图片、语音是你装好的剧情本体，删了就得重装。 所以下面的清理项都不动它们。

其余都能回收：资源包缓存是下载回来的原始压缩包，装完就没用了； 导出成品、日志、下载残留删了也不影响任何功能； 高清图删掉会自动用回原图（画质变回去而已，能重做）。

清理空间

每一项都先告诉你"删了会怎样"。删除不可撤销，但下面这些都不会让你丢剧情， 删的只是"用完就没用"的东西。

资源包缓存统计中…

这是下载回来的原始压缩包。安装时已经解开成图片 / 语音 / 剧本， 所以删掉不影响播放；只有重新安装那部剧情时才会再下一次。

未被引用的缓存先扫描（不删），看清楚再决定

卸载过的剧情、或者官方改过名，旧压缩包会留在缓存里没人用。 这里只删没有任何已装剧情在用的包；背景 / 音乐 / 音效 / 头像这些公共素材一律保留。

已被超分覆盖的原图—

只删已经有高清版的原图，删完照样播放（播放器用高清版）。 不可撤销：想反悔要重装那部剧情。

超分高清图统计中…

删掉后立刻用回原图播放，不会黑图、不影响剧情；代价只是画质变回去， 想再要高清得重新跑一次（比较慢）。临时腾空间才建议删。

导出成品统计中…

userdata/export/ 里的视频、CG 压缩包、导出的翻译 txt。 你想要的先拷走再清，删了之后要重新导一次。

日志与下载残留统计中…

日志只用于排错，随便删（正在写的那个文件会被占用，跳过即可）； 下载残留是中断下载留下的临时文件与视频导出的临时上传文件。

卸载

本程序是免安装的便携程序：不写注册表、不装系统服务、不往 Program Files 或 AppData 里塞东西。 删除整个程序文件夹就等于完全卸载，不会留下任何残留。

唯一的例外是你自己生成的东西，都在程序文件夹里的 userdata/： 已下载的素材、译文、导出成品、日志、设置。
想保留就先把 userdata/ 整个拷出来；想彻底清净就一起删掉。 删之前记得先点上面的「停止本地服务」（或直接关掉那个黑色命令行窗口）， 否则文件被占用、删不干净。

帮助

这个项目是什么

把《超昂大战》的角色个人剧情做成能离线翻阅的阅读器：还原原作演出（背景 / 立绘 / CG / 语音 / 音乐），可以导入中文译文，也能导出视频和 CG。

程序是开源的，游戏素材不在里面 —— 第一次用要去「剧情安装」页 自己下载。中文译文也不附带，需要自己翻或用 AI 翻了导进来。

三步上手

  1. 下载基础数据：去左边「① 概览 / 快速开始」点「下载基础数据」。 背景音乐和音效是所有剧情共用的，一次下齐省事。
  2. 装剧情：「② 剧情安装」→ 勾想看的角色 / 章节 → 点「开始安装」。
  3. 看剧情：回「角色剧情」→ 左侧点角色就能播。想要中文就点播放器里的「翻译」。

常见问题

点角色提示"资源还没有下载"

这部剧没装。回「剧情安装」，勾上它（可以按名字搜索），点「开始安装」。 装完它会自动出现在播放器里。

有画面但没声音 / 没有背景音乐

先检查「基础数据 → 公共素材」下过没有：背景和 BGM 是所有剧情共用的， 不下就只有你装过的那几部剧情自带的音效。 如果已经下过还是没声音，点一下画面再播（浏览器会拦截自动播放）。

立绘缺脸 / 显示不完整

约 10% 的特殊立绘在原作里本身就是分层图（缺脸部部件）。播放器设置里勾上 「显示不完整立绘」可以看到底图。

下载很慢

把「剧情安装」页的下载速度调到 32 最省时间；老是失败就降到 8–16。 另外下载前先关掉代理软件——代理按流量计费，一部剧情 30–60 MB。

磁盘满了 / 想清理空间

去「设置 / 清理空间」页，那里把占空间的东西按用途列全了， 并告诉你哪些删了不影响播放：资源包缓存、没用的旧缓存、 已经被高清版替代的原图、导出成品、日志。 只想删某一部剧情，就在「剧情安装」里点那一行的「卸载」。
