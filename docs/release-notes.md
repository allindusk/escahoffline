
# 超昂大战 · 角色个人剧情离线阅读器 v{VERSION}

把《超昂大战》的角色个人剧情做成能离线翻阅的阅读器：还原原作演出
（背景 / 立绘 / CG / 语音 / BGM），支持导入中文译文，可导出视频与 CG。

## 本版本更新内容

> 每次发版在下面追加一条，**新版本写在最上面**。下面的 `v{VERSION}` 会在构建时
> 替换成实际版本号；更早的版本留在下面即可（不会自动替换）。
> 这里只写「修了什么 / 加了什么」，方便用户点「检查程序更新」时直接看到。
>
> **只有最上面那一节（带 `v{VERSION}` 的 `###`）会进 Release 正文**：
> 构建时由 `tools/release_notes_body.py` + `server/release_notes.py` 裁出来，
> 因为控制台的「检查更新」是原样显示正文的（2026-11-03 用户要求：只留更新版本的
> 更新和修复内容）。下面的历史版本、下载说明、注意事项只给仓库里的人看。

### v{VERSION}（2026-11-14）

**修复**
- **活动 / 主线剧情第一段「只有字、没有画面」，第二段「有画面、没有字」**：
  官方的剧本把「标题」单独放在第一段（一句字幕 + 念标题的语音），画面其实在第二段开头。
  现在标题并进第一段：打开就能看到标题横幅和字幕一起出现，念标题的语音也不会再放两遍；
  活动剧情的段数也跟官方一览一致了（8 段的活动不再显示成 9 段）。
- **播放记录里名字太长的剧情，会把行尾的「⧉ 复制名字 / ✕ 删记录」挤到第二行**：
  现在标题按一行截断，两个按钮固定在名字右边。
- **批量导入译文时，主线 / 活动 / 其他剧情认不出来**：以前只认 `char_数字`、`adv_数字`
  这种名字，`adv_main_10`、`adv_tutorial` 会被当成「认不出是哪部剧情」而跳过。
  现在都能正常导入。

**调整**
- **侧栏列表不再挤「第 1/8 段 2%」**：一行里已经有段数、句数、语音数和收藏星，
  再塞进度就会把行尾的按钮挤出界。播放进度看鼠标移上去的浮窗，那里写着
  「上次看到：第几段 · 第几句（百分比、多久以前）」。
- **资源管理页「翻译」卡片改成「608 / 613 部」**：613 部里有 5 部漫画活动整集都是图、
  一句台词都没有，剩下 608 部全部译完。以前只写「608 部剧情」，容易被当成剧情总数。

### v1.1.4（2026-11-14）

**新增**
- **把当前画面和台词拼成一张图分享**：顶栏新增「分享」按钮（在「局域网二维码」左边）。
  点开后会停住画面，把背景、立绘、CG 照原样重画一遍，再按你勾选的顺序把台词排在图片下面。
  默认从正在看的这一句起自动带上下 3 句，最多拼 20 句；可选 1080p / 720p，
  首句可以画成播放器里的对话框，也可以画成在海报上的金色名字 + 台词，字号大小可调。
  出图是占空间小的 JPG，能下载保存，也能一键复制、直接粘到聊天窗口里发出去。
- **播放记录列表改成和角色列表一样的卡片**：有横幅、名字和进度信息，
  鼠标移上去能看到稀有度、共几段、上次看到第几句、资源是否已就绪；
  行尾新增「⧉ 复制名字」，想单独发某个记录的名字不用再手打。

### v1.1.3（2026-11-11）

**新增**
- **表情符号与画面特效按官方素材演出**：汗、怒、落寞等气泡贴在角色脸边、会跟着动作走，
  剧本喊清除时才消失；集中线、光晕等分「立绘后面 / 画面前面」两层，持续型的一直演到脚本清除。
  第一次用会自动补下「剧情演出特效」（约 7 MB）。
- **换场景不再硬切**：背景与 CG 的出现、隐藏、擦除方向与时长全按脚本演，段与段之间也一样。
- **立绘按游戏原坐标摆放**：位置和大小用官方落点表，多人同框也不再统一缩小、不再贴着底部。
- **动作演对了**：走过去 / 后退（纵向位移以前整个丢失）、坐下起身、弹出、点头、突刺、抖动，各按脚本演。
- **说话人自动变暗**：没写「谁在说话」的剧情也能按角色名认出说话人，其他在场角色压暗；
  旁白和「一同」说话时保持原样，不会把人全暗掉。
- **染色不再一帧跳变**：染色类演出按脚本时长平滑过渡（以前是啪一下变色，看着像闪）。
- **控制条「自动」关掉后**：播放键变成「▶ 下一句」，按键说明同步改口，点画面也是进下一句。
- **补全素材写得更明白**：只补缺的类别、不重跑已齐的；进度条标出「下载 / 解包」，
  网速不再出现 400 MB/s 这种假数字。

**修复**
- **播完一段再进下一段，画面不动了**：上一段留下的 CG 压住新场景（这类衔接有 153 处），
  现在旧 CG 会自动退场，新背景正常显示。
- **老安装的立绘小一圈、表情气泡跑到头的另一边**：落点表随更新一起下发，更新一次即好。
- **「补全缺失」跑完了按钮还亮着、数字不刷新**：任务结束会自动更新。
- **启动窗口刷「找不到文件」红字**：缺失的可选特效文件不再报 404。

### v1.1.1（2026-11-08）

**新增**
- **一段播完会自动接着播下一段**：画面停住，对话框里写「第 N 段播放完毕 ·
  3 秒后自动播放第 N+1 段」并倒数。按暂停、换段、快进都会立刻取消这段等待。
  角色剧情播完倒数第二段时会停住，最后一段留给你自己点（免得一次播到底又从头看）。
  关掉控制条的「自动」就只提示、不续播。

**修复**
- **v1.1.0 装不了任何剧情**：点「开始安装」几秒后必定失败，报
  `name 'FILES_STORY' is not defined` —— 资源都下载成功了，却一部也装不上。
  现已修好，可以正常装完并播放。
- **装剧情失败后页面一直闪、滚动条反复跳回顶端**：失败的任务会在底部条停留 40 秒，
  这期间列表被每 1.5 秒重画一次。现在一次任务只刷新一次；刷新时也不再丢掉
  你正看着的位置。
- **启动时窗口刷一串「找不到文件」**：头像和剧情横幅本来就不随程序分发，官方刚
  上新的角色本机还没有图，以前照样会去请求。现在只请求磁盘上确实有的图，缺的就
  画首字色块；装完剧情或素材后立刻生效，不用重启。
- 缺素材的这类「找不到文件」不再写进启动窗口（日志里仍可查到）。

### v1.1.0（2026-11-06）

**新增**
- **装剧情失败时，能看出是哪一类问题**：不再只有一句「剧本解析失败（包可能损坏）」。
  现在分开说清是「没下下来 / 下了一半 / 磁盘或权限装不进 / 剧情目录过期」，
  并直接给出下一步该做什么（点「更新」刷新目录、换下载源、腾出磁盘、关掉代理…）。
  每条错误的开头有一个短码（如 `E-NET`），截图时带上它就能定位问题。
- **「操作记录」里可以看完整报错**：记录栏只留一行摘要，点「详情」开浮窗看全文，
  可以选中、可以点「复制这段」；右上角「复制错误信息」一次性复制运行信息
  （版本 / 系统 / 最近几条错误 / 日志末尾），方便自己留存或发给别人看。
- **文字提示停留时间跟着字数走**：以前不管多长都只显示 1.6 秒，「发现哪几部剧情
  没下载」这种长句还没看清就消失了；现在长句最长停 6 秒，而且会自动换行，
  不会再横向撑出屏幕。
- 更新剧情目录的说明里加了一句：建议官方开服 1 小时后再点更新。

**修复**
- **漫画类活动剧情在列表里看不到**：官方有 5 部活动是「整集都是 CG 逐格翻页、
  一句台词都没有」，以前被当成空包剔除 —— 资源管理显示「已安装」，播放器侧栏却
  永远没有它们，还会弹一句「发现 5 部新剧情（未下载）」。现在按「有没有画面演出」
  判断，这类剧情正常出现在列表里。
- **装剧情失败却只说「包可能损坏」**：真实原因（下载失败 / 磁盘满 / 目录写不进 /
  剧情目录过期）被吞掉了。现在按原因说清楚；如果是目录过期，会先自动刷新目录
  再重试一次，不必自己反复重装。
- **一边装剧情一边清理空间，会把那部剧情装坏**：清理资源包会删掉正在安装的剧情
  刚下好的文件，最后只报一句「剧本解析失败」。现在安装期间会拦住清理并说明原因。
- **语音没声音、立绘空白、头像缺失却不提示**：语音包解不开、立绘一张都没合成、
  头像裁不出来，现在都会在操作记录里明确写一行「会导致什么、怎么处理」。
- **报错了但操作记录里一条都没有**：几秒内就失败的（缺安装组件、找不到这个包）
  会在两次刷新之间结束，以前只记录「正在跑」的任务。现在刚失败的也会补一条，
  并带上运行环境。
- **筛选后列表是空的，提示却像坏了**：「只看未安装」下明明全部装好，却说
  「把筛选切回全部剧情查看」；现在直接说清「这一类 613 部全部已安装」。
- 清理空间页「下载残留」的说明改成实际情况（只有没下完的临时文件，
  删了不影响已装剧情和已导出的视频）。

### v1.0.9（2026-11-04）

**新增**
- **新角色 / 新剧情不用等程序更新**：官方刚实装的角色，更新一次资源就会出现在列表里，
  稀有度和实装日期自动补上（名字从 Wiki 自动对号；对不上就先显示 ID，绝不猜错）。
  主线 / 活动 / 其他里还没装的也都列出来并标「未下载」，点了会引导去资源管理。
- **「其他」新剧情自动归类**：装上一部新的「其他」剧情后按正文内容自动归进对应入口
  （殲滅戦 / RAID BOSS / 広域戦 / 纪念活动…），没认出来的先放在「未归类 / 新上线」，
  不会再出现「装完反而从列表里消失」；官方只放了空占位包的会标「空包」。
- **文本框外观三档**：设置面板多了「文本框外观」——有边框（默认）/ 无框 + 柔和底衬 /
  无框 + 纯文字（像字幕）。选无框后「背景不透明度 / 背景色」两个控件会变灰
  （无框时本来就不生效），免得拖了没反应以为坏了。

**修复**
- **某些剧情会卡在一句话上不动**：剧本里有些「等玩家点击」的标记被当成了
  「要等 100～255 秒」，于是画面停住、点暂停再点播放还是卡回原处
  （例：天使型·艾斯卡蕾雅第 1 段第 22 句「？」之后）。现在这类标记按正常演出
  时长处理，全站三千多处同类情节（含漫画分镜那种一页一停的）都不会再停住。
- **任务进度条把下载量说成「个数」**：一个不到 1 MB 的更新包显示成
  「已完成 0/933450 个」，看着像在偷下东西。现在下载只看「x MB / y MB」；
  解包、超分、转码、清理、导出这些才显示「x/y 个 / 张 / 部」；下载完就写
  「已下载 x MB」，不再挂着还在跳的网速。
- **右侧「本段文本」的台词被截断**：以前超过 3 行就只剩省略号，回看时看不到后半句；
  现在一律完整显示，并保留原文里的换行。
- **CG 页角色数比剧情页少一个**：两页统一按「认得的全部角色」算（385 个），
  还没有 CG 的新角色点进去会说明「装好这部剧情后自动出现」。
- **控制台的「公共素材」自相矛盾**：背景改成按「已装剧情引用到的张数」算，
  引用到了却没图才算缺，不会再出现「601/612」却写着已就绪；那一行说明也不再被
  省略号裁掉。

### v1.0.8（2026-11-03）

**新增**
- **收藏夹**：播放器左侧列表每一行右侧一颗星，CG 页每张卡片左上角一颗星（按「一组 CG」收藏，
  灯箱里也能点）；筛选框里多了「只看已收藏」。收藏状态两个页面共用同一份，装剧情、
  换分类都不会丢。
- **播放记录**：筛选条最右边多了「播放记录」，点一下左侧列表换成「最近看过什么」，
  跨角色 / 主线 / 活动 / 其他按时间倒序排，点任意一条**接着上次看到的那一句**继续看；
  记录攒多了可以一次清空。
- **自动接着看**：每段剧情都会记住看到第几句，侧栏点进来直接定位，列表行上还标着
  「第 2/5 段 · 45%」；这一段已经看完了才当「从头再看」。
- **设置和收藏跟着人走**：播放器设置（音量 / 字号 / 显示项…）、列表分类与筛选、
  CG 的显示范围与大小、界面语言，除浏览器自身存储外再存一份到程序目录（`userdata/`），
  换浏览器、清缓存、手机扫码进来看见的都是同一套。这些文件只在本机，不上传、不联网。

**修复**
- **拖进度条 / 点台词 / 从播放记录跳进去后 BGM 没了**：跳转现在会把「这个位置本该在放的」
  音乐和循环音效补上（只补状态，不重放一次性音效），不再出现跳一次就安静到底。
- **点进度条 / 跳句时画面黑闪一下**：同一张图改为直接复用，真换图才新旧交叉淡入，
  任何时刻画面上都有图，不再先清空再淡入。
- **「重播」「自动播下一段」又跳回上次那句**：重播从这一段开头播、自动续播从下一段开头播，
  不再被旧进度拽回去。
- **主线 / 活动 / 其他的列表没有筛选**：排序和 SSR/SR/R 只在角色分类显示，
  「已下载 / 未下载 / 已收藏」对所有分类都有效。
- **容量明细里的目录看不见**：目录以小字排在体积后面（过长省略号，悬停看全），
  不用再把鼠标停在整行上猜。
- **小修**：手机端 CG 灯箱顶栏的收藏只留星星（不然角色名被挤掉）；新手引导文案跟着新按钮更新。

### v1.0.7（2026-11-03）

**新增**
- **「其他」分类按入口分组**：剧情安装页的「其他」不再是一长条「其他剧情 第N话」，
  改成按入口分组（各 RAID BOSS / 広域戦 五个职种 / 記念イベント / 教程…），
  组头带入口的章节横幅，可以折叠；和播放器左侧「剧情列表」完全对得上。
- **剧情列表显示章节封面**：主线 / 活动 / 其他只下载了部分时，也能看到每话的标题横幅。
- **翻译教程**：翻译页和播放器的翻译面板都加了「自己动手翻 · 5 步教程」，
  讲清导出原文 → 交给 AI → 存成 txt → 导回 的全过程，并给出可以直接复制的提示词。
- **译文导出 / 导入更明确**：导出写完会显示文件名和保存位置，旁边按钮直接打开文件夹；
  导入支持 txt、整个文件夹、zip 压缩包。
- **版本内置数据的口径统一**：概览页的体积 / 耗时全部来自同一份数据，
  不会再出现「约 约 24.7 GB」这种重复词或前后不一致的数字。

**修复**
- **装完剧情后角色名被改错、稀有度/实装日期消失**（重要）：以前装一部剧情会按名字表
  整体重写角色名单，导致 22 个角色名被换成别人的名字、11 个角色丢了稀有度/实装日期/
  职业（按 R/SSR 筛选也筛不到）。现在只在名单里**补充新角色**，已有角色的名字一律沿用，
  元数据只补不删。
- **一次勾多部安装时进度条倒退 / 提前到 100%**：以前装 3 部会在 33%→66%→33% 之间来回跳，
  第 2 部结束就显示 100%；现在按「第 i/N 部」平稳推进，不到最后一部不会到 100%。
- **进度条出现「已下 5.63 MB / 总量 0.01 MB」**：总量预估偏小时分母不再小于分子。
- **操作记录里剧本包显示成一整段 `{bundle_name…}`**：只显示包名和大小。
- **章节封面张数统计少一张**：某张图写盘失败时不再被算进「应有张数」。
- **打开页面时控制台刷一片 404**：译文清单的统计口径统一了，没译过的剧情不再被逐个请求；

## 第一次用

1. 解压 portable 包到一个**路径里没有中文和空格**的目录，双击 `启动.bat`
2. 打开「资源管理」页 → 下载**基础数据**（资源清单 + 公共素材）
3. 再到「剧情安装」勾想看的角色，点「开始安装」
4. 装完回「角色剧情」页，点角色就能播
