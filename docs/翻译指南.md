# 翻译指南（用 AI 把剧情变成中文）

> 这是本项目**投入产出最高**的玩法。播放器已经把工程问题解决了（导出、对照、
> 合并、术语、校验），剩下的只有"翻得好不好"。

---

## 1. 为什么用 txt，而不是直接改 JSON

对话文本是**以日文原文为 key** 存的（`{"「おはよう」": "「早上好」"}`）。
直接编辑 JSON 有三个坑：容易漏逗号、编码容易坏、非程序员改起来痛苦。

所以中间层用一份**单行对照文本**：

```
# ===== ESCAH 离线阅读器 · 剧情译文文件 =====
# 剧情标识 : char_1
# 剧情名称 : 角色 1 · 神騎プラチネル
# 段落/句数: 6 段 / 812 句
#
# 使用说明（给人和 AI 都看得懂）：
#   1. 每行一句，格式为：   日文原文 ||| 中文译文
#   ...
# ============================================

「おはよう」 ||| 
そんなこと言われても…… ||| 
```

- 分隔符固定 `空格|||空格`
- **左边原文一个字都不能动**（它是匹配 key）
- 原文里的换行被写成 `\n`，别改
- 想跳过某句就把右边留空（该句回退显示日文）

导入时服务端会逐行解析并合并，告诉你有多少新增 / 更新 / 跳过 / 格式错误。

## 2. 完整流程

### 第一步：导出

播放器打开任意一部剧情 → 控制条「译文」→「⬇ 导出原文」→ 得到 `char_<id>.txt`。

也可以在「资源管理 → ⑤ 译文」里对已安装的其他剧情批量处理（见第 5 节）。

### 第二步：交给 AI

把 txt **整个文件**发给 AI，附上下面的提示词（按需微调）：

```
你是日译中翻译，擅长日本 Galgame / 手游剧情的口语化翻译。

附件是《超昂大战》的剧情台词对照文件，格式是：日文原文 ||| 中文译文。
任务：把每一行右侧填成中文译文。规则：

1. 左侧原文一个字都不能改（包括标点、空格、\n），它是对照用的键。
2. 右侧只写译文，不要加解释、不要加引号、不要改动分隔符。
3. 保留原有的「」『』（）等符号用法；台词里的停顿、拉长音用中文习惯表达。
4. 语气要口语化、贴近角色性格；同一角色前后称呼必须一致。
5. 拟声词（ドキドキ、ふわぁ…）译成中文拟声/状态描述，不要留日文假名。
6. 遇到露骨的性描写：只翻真正露骨的部分，拟声、惊叫、擦边、玩笑照常翻，
   不要因为"看起来敏感"就整段跳过。
7. 输出：完整文件的文本（含开头的注释行），不要省略任何一行。

以下是术语表，出现时必须按它翻：
<把你的术语表粘进来，或用 output/custom_dict.json 里的核心条目>
```

> 一次性给太多行会超出上下文。超过 ~800 行建议**按段落切分**（文件里每个 part 是
> 独立剧情段），一次给 1–2 段的量，翻完再合并。

### 第三步：导回

播放器「译文」面板 →「选择译好的 txt…」→ 确认模式：

- **合并**（默认，推荐）：只覆盖右侧非空的行，已有译文保留
- **覆盖整部**：丢掉这部剧情原有译文重新写

点「✅ 导入并应用」→ 会显示 `新增 X · 更新 Y · 跳过 Z · 格式错误 N` → 按 `F5` 刷新。

如果有"格式错误"，通常是某行中间的 ` ||| ` 被改坏了（比如被替换成全角 `｜｜｜`，
或者 AI 加了 `译文：` 前缀）。用编辑器搜 `|||` 检查那几行。

## 3. 质量要点

### 术语统一

项目自带术语表 `output/custom_dict.json`（约 800 条日文 Galgame 常用词），
建议把其中与你剧情相关的条目贴进提示词。

**容易翻错的**（务必注意）：

| 日文 | 正确 | 错误 |
|---|---|---|
| ダメージを回復 | 恢复**所受伤害** | 恢复体力 |
| スタミナを回復 | 恢复**体力** | 恢复伤害 |
| 自身のダメージを完全回復 | 自身所受伤害完全恢复 | 自身完全恢复 |
| 継続回復（未指明对象） | 持续回复（保持中性） | 强行补成"持续回血" |

### 排版

不要逐字对着日文断行。**整句理解后按中文语境重新断行**，分段数不必与原文一致。

### 人名

角色名保持日文原名或统一用社区通用译名，**全篇一致**；同一角色不同称呼
（お兄ちゃん / 兄さん / あなた）要体现场合差异，不能一律"哥哥"。

### 露骨内容

按语义逐句判断：只有真正露骨才留空跳过，拟声、惊叫、习语、擦边都可以照常翻。
过度保守会让整段剧情读起来断裂。

## 4. 批量与进度

- 「资源管理 → ⑤ 译文」看当前译文库总量（多少部 / 多少句）
- 每部剧情导出一次，翻完导入，互不影响
- 译文文件可直接分享给别人（只有文本，不含素材，风险低于素材）——
  但仍建议只在可信范围内交换

想用脚本批量处理，可参考：

## 5. 给做二开的人

译文层的实现只有两个函数，读一遍就能改：

- `server/exports.py::export_trans(unit)` → 生成对照 txt
- `server/exports.py::import_trans(unit, text, mode)` → 解析合并

相关约定：

- 译文仓库：`web/assets/i18n/zh-Hans/<unit>.json`，`{"messages": {"原文": "译文"}}`
- 索引：`web/assets/i18n/index.json`（各语言句数，用于显示覆盖率）
- 前端加载：`web/assets/js/i18n.js`（`loadStory(unit)`）
- 想加繁体/英文，把 `zh-Hans` 换成对应语言目录，并在 `i18n.js` 的 `supported` 里登记

如果你要做"AI 自动翻译流水线"（批量调 API），
建议复用 `import_trans()` 做落盘，别自己拼 JSON。
