
# 超昂大战 · 角色个人剧情离线阅读器 v{VERSION}

把《超昂大战》的角色个人剧情做成能离线翻阅的阅读器：还原原作演出
（背景 / 立绘 / CG / 语音 / BGM），支持导入中文译文，可导出视频与 CG。

## 本版本更新内容

> 每次发版在下面追加一条，**新版本写在最上面**。下面的 `v{VERSION}` 会在构建时
> 替换成实际版本号；更早的版本留在下面即可（不会自动替换）。
> 这里只写「修了什么 / 加了什么」，方便用户点「检查程序更新」时直接看到。

### v{VERSION}（2026-11-02）

**新增**
- **局域网访问**：播放器右上角新增「局域网访问」按钮，点一下出二维码和文字地址，
  手机连同一 WiFi 扫码就能打开。启动脚本默认监听局域网（`--host 0.0.0.0`），
  启动时会直接打印手机可访问的地址。
- **手机 / 平板适配**：三个页面都做了窄屏布局。播放器的左右侧栏改成抽屉（点边上的
  把手开合，选完剧情自动收起），CG 页新增「☰ 角色列表」开关，资源管理页把左侧竖排
  导航改成顶部横向滚动条。
- **竖屏控制栏改为五行居中**：重播·播放·下一段 / 进度条 / 倍速·自动·对话框·全屏 /
  翻译·设置·? / 版本·免责声明。所有功能一屏可见，不用再横向滑动去找按钮。
- **手机横屏**：顶栏和控制条压回单行，把高度让给画面（舞台可用高度 149px → 239px）。
  竖屏首次进入会提示「横屏观看画面更大」，点一下就不再提示。
- **全屏**：全屏时控制条和「✕ 退出全屏」一起显示，静止 2.6 秒自动淡出，动一下就回来；
  手机上全屏**单击只唤出控制条、双击才暂停/继续**，不会一看按钮就把播放停掉。
  iOS Safari 不支持 div 全屏时自动改用铺满视口的伪全屏。
- **手机上不适用的功能会拦一下**：超分、导出视频、打包 CG、打开本地目录、删除/清理、
  停止本地服务、程序更新，在手机上点击会弹窗说明「这个功能请在电脑上使用」，不会真执行。

**修复**
- **顶部 ◀ ▶ 按钮点了画面没反应**：它们原来只是把段标签横向滚一下，现在改成真正的
  「上一段 / 下一段」，多段时常驻显示。
- **手机上点剧情后 PC 端的悬停浮窗一直挂着挡画面**：触屏设备不再触发悬停浮窗。
- **手机上设置页关不掉、只能刷新**：关闭按钮原来落在屏幕左侧中间、被「剧情列表」
  把手挡住；现在固定在右上角并加大。设置面板同时改为真正铺满、盖住两侧把手。
- **局域网二维码给出手机连不上的地址**：开了代理（Clash 等 TUN 虚拟网卡）时会拿到
  `198.18.x.x`，现在优先选 `192.168.*` / `10.*` / `172.16-31.*` 的内网地址。
- **资源管理页手机适配**：顶栏从三行压回两行；底部任务条改四行堆叠不再横向溢出；
  「操作记录」默认收成右下角小框，有新记录只在标题上点个小圆点提示。
- **控制条「翻译 / 设置 / ?」被右下角版本条盖住**（桌面）已让位。

**数据**
- 剧情 / 活动标题补充与修正。

### v1.0.5（2026-11-02）

**新增**
- **「其他」剧情按游戏里的入口重新分组**：现在是 **17 组 / 196 话**，话名直接用游戏里的
  （`Gハニー来襲 その1`、`忍者 3`、`2024年エイプリルフール その5`、`祝！3.5周年！！`…）。
  以前是靠关键词猜的 12 组 150 话，还把広域戦那几个多段包错归进了 H シーン集。
- **画质对比**：画质页新增「看看能清楚多少」，左边原图、右边超分 2 倍，中间竖线可拖动，支持全屏。
- **左侧剧情列表可收起**（点按钮或按 `[`）。
- **剧情标题自动识读**：主线/活动/其他的标题从剧本首段与封面读出来，不再一律显示「第N话」。
- **CG 页把两类 CG 分开**：角色 CG（384 个角色）与「主线 / 活动 / 其他」剧情 CG 分范围切换；
  剧情 CG 也能打包导出。
- **翻译页**：新增「全选已翻译 / 全选未翻译」（只作用于当前筛选结果），导出按钮挪到同一行最右。
- **播放器**：段数多时标签条不换行、右边出 ◀ ▶ 翻页；进度条可点击跳转（暂停时只跳不自动播）；
  快捷键说明收进控制条最右侧的「?」按钮。

**修复**
- 点「其他」分组、点某一话之后，左侧列表跳回顶部（滚动位置现在统一保护，被点的分组停在原位）。
- 左侧列表中间凭空多一条空条、底部一条黑白横条（搜索计数恒占 20px；列表内容宽出 5px 冒出横向滚动条）。
- 控制条最右边的「翻译 / 设置 / ?」被右下角版本条盖住、点不到。
- 下载进度「到 100% 却一直不动」：下载与解包现在分阶段计入同一条进度条。
- 补全资源时进度显示成「70.9% · 8.40 MB / 893.01 MB」（分母是全量、分子只算本次新下的）。
- 控制台个别按钮点一下没反应（请求体被判空，后续请求还 501）。
- 两处官方数据自带的标题乱码，已按封面重新识读。

### v1.0.4（2026-11-01）
- **修复：剧情译文不加载（一直显示原文）**
  播放器探测「有没有译文」时请求了错误的路径 `assets/i18n/zh-Hans/index.json`
  （该文件实际不存在），导致判定为「没有译文」，于是逐条 `char_<id>.json`
  永远不被加载。改为请求正确的顶层清单 `assets/i18n/index.json` 后，
  译文恢复按角色懒加载。
  **属于程序 bug，升级后自动修复，无需重新下载译文。**

## 第一次用

1. 解压 portable 包到一个**路径里没有中文和空格**的目录，双击 `启动.bat`
2. 打开「资源管理」页 → 下载**基础数据**（资源清单 + 公共素材）
3. 再到「剧情安装」勾想看的角色，点「开始安装」
4. 装完回「角色剧情」页，点角色就能播
