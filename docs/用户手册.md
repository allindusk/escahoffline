# 用户手册（小白版）

> 从零到"能看剧情"，大约 10 分钟（取决于你的网速）。
> 遇到问题先看最后的「遇到问题怎么办」。

---

## 一、先明白一件事

这个工具是**播放器**，不是游戏本体，**也不含素材**。

游戏里的立绘、语音、剧本都不在安装包里（那部分有 24.7 GB，而且版权不在本项目）。
所以第一次打开时**一部剧情都放不了**，侧栏角色全是灰的「未下载」——这是正常的。

你要做的是：**装资源包**。装好之后就能离线看。

---

## 二、安装与启动

### Windows（推荐便携版）

1. 到 Releases 页下载 `ESCAH-Offline-vX.Y.Z-win64-portable.zip`
2. 解压到**一个你找得到、路径里最好别有中文和空格的目录**，例如 `D:\ESCAH`
3. 双击里面的 **`启动.bat`**
4. 会弹出黑色命令行窗口（**别关它**，关了网页就用不了），然后浏览器自动打开

如果命令行窗口一闪就没了：多半是解压不完整，或被杀毒软件拦了。
右键 `启动.bat` → 以管理员身份运行试试；仍失败就把窗口里最后几行报错记下来去提 Issue。

### 源码方式（会用命令行的人）

```bash
git clone <仓库地址>
cd escalation-heroines-offline   # 目录名以实际为准
pip install -r requirements.txt
python -m server --open
```

### 启动后你会看到三个页面

| 页面 | 干什么 |
|---|---|
| `setup.html` **资源管理** | 下载资源、超分、导出、译文、更新、设置 ← **先来这里** |
| `index.html` **角色剧情** | 看剧情 |
| `cg.html` **角色 CG** | 看 CG 图库、导出 CG |

## 三、第一次装资源

1. 打开「资源管理」（右上角导航，或启动时默认打开的就是它）
2. 页面顶部「**基础数据（必需）**」→ 点「下载」拿到**剧情目录**（约 5 MB）
3. 想让所有剧情都有背景和音乐，顺手点「**公共素材**」的下载（约 835 MB，只需一次）
4. 再到「**剧情安装**」页，**挑一部剧情**勾上 —— 列表和播放器左侧一样分
   **角色 / 主线 / 活动 / 其他**四类，可按名字搜，也能按「实装日期」排序、
   只看未安装、按稀有度（SSR / SR / R）筛
5. 底部会显示"未选择 / 已选 N"，确认后点 **开始安装**
6. 底部出现进度条：百分比 / 已下大小 / 个数 / 速度 / 剩余时间，可暂停或取消

**要装多大？**

| 你的想法 | 装什么 | 体积 |
|---|---|---|
| 先试试能不能跑 | 核心 + 一个角色（不要公共素材） | ~55 MB |
| 正常看一个角色 | 核心 + 公共素材 + 该角色 | ~1 GB |
| 全都要 | 全部 615 个包 | ~24.7 GB |

> 公共素材（背景/立绘/音乐）是**很多剧情共用的**，所以只装一个角色也得带一份。
> 想省流量可以在底部取消勾「自动带上公共素材」，代价是没背景、没立绘、没声音。

**线程数怎么选？** 默认 4，绝大多数情况够用。慢就降到 1–2，快不了就 8。
详见安装页那一行「多线程下载是什么」的展开说明。

## 四、看剧情

回到「角色剧情」页：

- 左侧点角色 → 自动加载并开始播放（不用再找播放键）
- 上方「角色 / 主线 / 活动 / 其他」切换剧情类型
- **「其他」是按游戏里的入口分好的组**（RAID BOSS、広域戦、殲滅戦、記念イベント、
  エイプリルフール、Hシーン集…），点组标题展开，话名就是游戏里那些
  （`Gハニー来襲 その1`、`忍者 3`、`祝！3.5周年！！`…）
- 有 `未下载` 红色标记的角色排在列表**最后**
- 点未下载的角色会弹窗问你要不要跳去下载，不会让你对着黑屏
- 觉得列表占地方：点列表顶上「收起」或按 **`[`**，只留画面

### 段落 / 进度

- 标题栏里是**段**：多段剧情点这里换段。段数多到一行放不下时，右边会出现 `◀ ▶` 翻页，
  标签条不会换成两行
- 标题栏左侧写着 `第 3/6 段 · 47 句`，鼠标停上去能看到剧本内部文件名（排查用）
- **进度条可以点**：点哪儿就跳到那一段的对应位置。正在播就继续播；
  **已暂停的话只跳过去、不自动播**（等你看清楚再点播放）

### 快捷键

| 键 | 作用 |
|---|---|
| `空格` / `P` | 暂停 / 继续 |
| `回车` / `↓` / `→` | 下一句 |
| `↑` / `←` | 上一句 |
| 按住 `K` | 快进 |
| `S` | 显示设置 |
| `F` | 全屏 |
| `L` | 切换显示语言（日 / 中） |
| `[` | 收起 / 展开左侧列表 |
| `H` | 新手引导 |
| `Esc` | 关掉设置、快捷键卡片等浮层 |
| `D` | 调试面板（排查问题用） |

> 记不住也没关系：控制条**最右边那个 `?`** 点一下就是完整快捷键表。

### 手机上 / 另一台电脑也能看

播放器右上角有 **「局域网二维码」**，点一下弹出二维码：手机连**同一个 WiFi**，扫码就能打开；
另一台电脑把弹出来的那行地址直接输进浏览器也可以
（地址是本机局域网 IP，`启动.bat` 默认已经监听局域网）。

连不上时：多半是 Windows 防火墙拦了入站端口 —— 命令行窗口里打印了放行命令，
用管理员 PowerShell 执行一次即可（端口号见那片日志）。

### 觉得字小 / 对话框不好看？

点控制条右侧的 **⚙**：

- 字号、行距、描边、字体、对话框透明度与颜色
- 立绘高度、上下偏移、左右偏移
- 音量（BGM / 音效 / 语音）、打字速度、倍速
- 「优先使用超分图」：装了超分就开，觉得吃内存就关
- 「显示不完整立绘」：约 10% 的特殊立绘在原作里本来就是分层图（缺脸部部件）

所有设置立即生效并自动记住。

## 五、把画面变高清（可选）

「资源管理 → 提高CG画质」。原图不会被改动，随时能反悔，占多少空间在
「设置 / 清理空间」里看。

1. 先点右上角 **「查看效果」**：左边是原图、右边是超分 2 倍，中间那条竖线可以拖，
   还能全屏看。觉得值再往下做，不值就关掉——不会动任何文件
2. 选范围（不选就是全部已装剧情）、选倍率，点开始
3. 可以随时停下；做完在播放器里默认就会优先用高清图

> 比较吃电脑（CPU / 内存），建议先拿一部剧情试。

## 六、导出

### 导出视频

到「资源管理 → 导出（视频 / CG）→ 导出剧情视频」：

1. 选剧情：列表和播放器左侧一样分 **角色 / 主线 / 活动 / 其他**，
   能按名字搜、按实装日期排序、按稀有度筛（只列已安装的剧情）
2. 勾要导的剧情，可多选（换分类会清空勾选）
3. 勾段落（不勾就是全部）
4. 点「开始导出」，进度显示在页面底部

成品是 mp4，存到 `userdata/export/`。

> 导出是**实时渲染**的，所以导 5 分钟的剧情要等 5 分钟左右。
> 期间别关掉那个页面。

### 导出 CG

CG 页面上方先选**范围**，两类 CG 分开：

| 范围 | 内容 |
|---|---|
| **角色** | 384 个角色的 CG（768 组 / 4607 张） |
| **主线 / 活动 / 其他** | 剧情 CG（130 / 38 / 67 组），侧栏按「哪一部剧情」列 |

选好范围（还可以再点某一个角色 / 某一部剧情缩小）→ 点右边的 **「⬇ 导出 CG」**。
「全部角色」导的是 384 个角色，不含剧情 CG。

产物是 zip，按「角色/事件组」（剧情 CG 是「活动剧情CG/活动 第16话/第6段」）建好文件夹，
在 `userdata/export/`。

## 七、更新

### 资源更新（有新剧情了）

「资源管理 → ⑥ 更新 → **更新剧情目录**」。
拉完会告诉你有没有新剧情；公共素材有更新会自动补下。

### 程序更新

同一个页面 →「检查程序更新」→「下载并应用」。

程序会自动：下载 → 关闭自己 → 替换程序文件 → 重新启动。
**你的素材、译文、设置都不会丢。** 但还是建议偶尔备份一下 `userdata/` 目录。

## 八、让剧情变成中文

这是本项目最值得投入的地方。核心流程只有三步：

1. 播放器里点控制条上的「翻译」→「⬇ 导出原文」，得到一个 `.txt`
2. 把这个 txt 丢给任意 AI（文件开头就写着"给 AI 的说明"），让它只翻译右边
3. 回来后点「选择译好的 txt」→「✅ 导入并应用」→ 按 `F5` 刷新

要批量做的时候，用「资源管理 → 翻译」页：

- 列表上方四个按钮：**全选本类 / 全选已翻译 / 全选未翻译 / 清空**。
  后两个只看**当前筛选结果**（分类、搜索、已装/未装都算），所以可以
  "先筛出主线、再一键勾出还没翻译的"
- 勾好点右边的 **「导出所选剧情」**（在这一行最右），得到一个 zip，里面一部剧情一个 txt
- 翻好之后用「批量导入」（支持多个 txt / 整个文件夹 / zip）一次导回

详细写法和提示词模板见 [翻译指南.md](翻译指南.md)。

## 九、遇到问题怎么办

**先做这两件事**

1. 按 `F12` 打开开发者工具 → Console 标签，看有没有红色报错（有就截图/复制）
2. 播放器里按 `D` 打开调试面板，能实时看到出错信息

| 现象 | 原因与处理 |
|---|---|
| 双击 `启动.bat` 窗口一闪就没 | 解压不完整 / 被杀软拦（本包已内置 Python，正常不会因缺环境失败） |
| 浏览器打不开页面 | 命令行窗口被关了。重新双击 `启动.bat`；端口被占用时程序会自动换端口，注意看窗口里提示的地址 |
| 点角色提示"资源还没有下载" | 没装该角色的包 → 资源管理 → ② 剧情安装 → 搜到它勾上（或按「只看未安装」筛出来） |
| 有画面没声音 | ① 没装公共音乐音效包 ② 浏览器拦截自动播放，点一下画面 ③ 这部剧在列表里标着「缺语音」→ 点行尾的「补齐」（只下缺的语音，不用重装） |
| 立绘缺脸 | 原作就是分层图，设置里勾「显示不完整立绘」 |
| 下载卡在 0% | 直链过期/需要 Referer/不支持 Range → 换线程到 1，确认链接能直接下载 |
| 下载到一半失败 | 点「开始安装」重来即可，会**断点续传**，不会从头下 |
| 装完但还是黑屏 | 看 Console 报错；大概率是 `web/media` 里文件被改名了（不要手改素材文件名） |
| 页面样式很奇怪 | 是不是用 `file://` 直接双击 html 打开的？必须用 `启动.bat` 走本地服务 |
| 想彻底重来 | 删掉 `userdata/state.json`（会忘记"已安装"记录，但不删文件），或整个 `userdata/` |

**要提交问题请带上**：程序版本（页面标题旁）、操作系统、Console 报错截图、
`userdata/logs/errors.log` 的最后几十行（如果有）。

## 十、几句话的规矩

- 自己私下用可以；**不要传播素材、不要商用、不要到处宣传**
- 不要下载来路不明的"整合包"，可能夹带恶意程序
- 详见仓库根目录 `NOTICE.md`
