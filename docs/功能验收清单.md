## 0. 项目长什么样

三个页面 + 一个本地服务端（纯标准库 + 4 个解包依赖）：

| 页面 | 地址 | 干什么 |
|---|---|---|
| 角色剧情 | `index.html` | 看剧情、导入译文、导出视频 |
| 角色 CG | `cg.html` | 看图库、导出 CG |
| 资源管理 | `setup.html` | 装剧情、调画质、导出、译文、更新、设置 |

启动：双击 `启动.bat`（便携版）或 `python -m server --open`（源码）。

**首次顺序**：免责声明弹窗 → 新手引导 → 控制台「剧情安装」。
没有资源时侧栏角色全标「未下载」，这是正常的。

## 4. 建议的验收顺序（分 4 轮，约 50 分钟）

### 第一轮：能跑起来吗（10 分钟）
1. 双击 `启动.bat` → 浏览器打开控制台
2. [ ] 无痕窗口打开 → **先弹免责声明**，点掉才继续
3. [ ] 新手引导 5 步看完
4. [ ] 「基础数据（必需）」→ 下载清单 → 进度 0→50→100%
5. [ ] 勾 1 个角色 → 开始安装 → 底部进度条 → 状态变「已安装」
6. [ ] 回播放器点它 → 能播、有立绘、有声音
7. [ ] 全程**没有黑窗口闪一下**

### 第二轮：核心功能（15 分钟）
8. [ ] 按 H 重看引导（10 步）
9. [ ] 译文：导出 txt → 改两行 → 导回 → 刷新看到中文
10. [ ] 点一个未下载的角色 → 弹窗引导去安装

## 6. 隔离验收工具（本轮新增）

```powershell
python tools/acceptance.py --quick      # 30 秒：不装依赖、不联网，验降级引导
python tools/acceptance.py              # 3–5 分钟：装依赖 + 真实下载清单与一部剧情
python tools/acceptance.py --portable   # 等价 CI：用 embedded Python 3.11
python tools/acceptance.py --keep       # 保留临时目录便于排查
```

它做的事：

1. 把代码复制到 `%TEMP%\escah-accept-<时间戳>\`（**只搬索引，不搬素材和你已装的剧情**）
2. 建独立 venv（或 embedded Python）→ 依赖与你的本机环境完全隔离
3. 用新端口启动服务，跑一整套检查：接口 / 缺依赖降级 / 缺清单引导 / 下载清单 / 安装一部剧情 / 三个页面
4. 输出通过/失败清单，结束自动清理

**这次跑出来的两个真 bug**（都已修）：

| 问题 | 影响 | 修法 |
|---|---|---|
| `stages.py` 顶层 `from unityfs_probe import ...`，而它顶层 `import lz4` | 用户没装依赖时**服务直接起不来**，连界面都打不开 | 用 try/except 兜住，真正调用时才报明确错误（页面给出"去 启动.bat 装依赖"的指引） |
| 我加的"精确体积上报"把清单条目 dict 当字典 key | **任何没装过的剧情都装不上**（`unhashable type: 'dict'`） | 先过 `_entries()` 归一化 |

> 这两个都是"本机装了 611 部、缓存齐全"时**永远测不出来**的问题——只有隔离环境才能暴露。
