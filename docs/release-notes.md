
# 超昂大战 · 角色个人剧情离线阅读器 v{VERSION}

把《超昂大战》的角色个人剧情做成能离线翻阅的阅读器：还原原作演出
（背景 / 立绘 / CG / 语音 / BGM），支持导入中文译文，可导出视频与 CG。

## 本版本更新内容

> 每次发版在下面追加一条，**新版本写在最上面**。下面的 `v{VERSION}` 会在构建时
> 替换成实际版本号；更早的版本留在下面即可（不会自动替换）。
> 这里只写「修了什么 / 加了什么」，方便用户点「检查程序更新」时直接看到。
>
> **版本号三段都只用一位数（0–9）**：`x.y.z` 每段到 9 就进位
> （`1.2.9 → 1.3.0`、`1.9.9 → 2.0.0`），别写 `1.1.10` 这种两位数
> （规则见 `docs/资源包与发布.md` §5）。
>
> **只有最上面那一节（带 `v{VERSION}` 的 `###`）会进 Release 正文**：
> 构建时由 `tools/release_notes_body.py` + `server/release_notes.py` 裁出来，
> 因为控制台的「检查更新」是原样显示正文的（2026-11-03 用户要求：只留更新版本的
> 更新和修复内容）。下面的历史版本、下载说明、注意事项只给仓库里的人看。

### v{VERSION}（2026-11-25）

**修复与优化**
- **老角色被写成 2026 年才实装**：Wiki 没给实装日时，以前拿「你本机下载资源包的那天」顶上，重装过哪个老角色，那个角色就显示成重装那天。这些错误日期在升级后自动清掉；官方确实没收录的，就只记一个**包日期**（资源包源文件的日期，所有人一致），页面上单独标注，不当实装日。
- **按「实装日期」排序时顺序不对**：读取角色信息的名字写错了，日期一直读成空，排序实际退化成按编号。现在正常；没有实装日的开局老角色固定算「最早」（旧→新在最前、新→旧在最后），只在它们内部按包日期排。
- **NPC 立绘配上了别人的头像**（上一版引入）：4 开头那批图不是剧情头像，和同编号的立绘完全对不上人。现在这类立绘一律不挂头像，升级启动时会自动重建一次。
- **装完一部剧情，原声集 / 角色音声要按 F5 才出现**：现在装、卸、导出结束后列表自动更新，正在听的那首不会中断，滚动位置也不跳。
- 以后新下载的资源包会保留源文件的日期（看包本身的年代更准，重新装过也不会变成「今天」）。

### v1.2.2（2026-11-24）

**修复与优化**
- **CG 场景里点「下一句」会闪出一张背景图**（上一版引入）：CG 被先撤掉再淡回来，中间露出背景。现在 CG 先落定、同一张图直接复用，不再闪。
- **「倒下去 / 坐下 / 起身」的位移跨几句就丢**：这些是持续状态，以前切句只补目标句附近那一条，往前几句就站回去了。现在按整段顺序重放，坐下、倒地、移开的位置都会保留。
- **切句时染色、闪屏、持续特效、字号、说话人压暗会重新演一遍**：现在切句直接落到这一句应有的状态，不再每切一次闪一下。
- **切到「字幕已隐藏」的句子时，对话框会被重新打开**；关掉「对话框」设置后切句又会把它顶回来 —— 现在按剧本和设置来。
- **主线 / 活动里个别句子切过去没声音**：用了 `PlayVoice` 的台词以前不补播，现在和 `VOICE` 一样处理。
- **按住快进或连续快速切句时画面叠影**：转场来不及演完就叠下一层，现在快速推进直接硬切。
- **头像拿同一个人另一套服装顶替**：学生ランス 头顶着铠甲ランス的头像（e5032）。现在当前立绘没有对应头像就保持无头像；官方头像本身只有一张脸时，按当前立绘的脸部框现裁一张（学生ランス 已恢复）。

### v1.2.1（2026-11-24）

**修复与优化**
- **立绘「倒下去 / 坐下」演反了方向**：剧本里的纵向位移是「向上为正」，播放器直接当成屏幕坐标用，300 处「倒下去 / 低头」变成了往上飘。现在按原方向下沉；坐下按剧本给的距离落座，起身会回到原位。
- **结局大立绘只露出腰部**：全屏立绘的纵向落点也是反的，脸被顶出画面；现在从下方升起后停在正确位置，露出脸和上身。
- **手动逐句时背景 / CG 硬切**：点「下一句」换场景、CG 消失时以前是一帧闪过去；现在按剧本时长淡入 / 擦除 / 淡出（剧本本身标了硬切的地方仍保持硬切）。

### v1.2.0（2026-11-24）

**新增**
- **多了一个「网页全屏」**：全屏按钮现在给两个选项（全屏 / 网页全屏），Shift+F 也可以。网页全屏只把本站的菜单、剧情列表、文本区和底部播放条收起来，画面铺满窗口，适合一边看一边点别的窗口；按 Esc 或画面上的「退出网页全屏」就回来。
- **漫画剧情单独标出来了**：整集没有台词、全靠逐格 CG 翻页的官方漫画活动，现在列表里挂「漫画」标记，名字显示成「漫画 ゲーミング神騎」或「漫画剧情 第51话」，状态写「可播放」，不再被当成缺素材。
- **点一次「更新」就把该更新的都更新**：刷新剧情目录时会顺手重建本机已装剧情的标题、漫画标记、排序和「其他剧情」的分组；官方往旧的横幅里加了新章节，也会重新下载并导出。
- **装剧情顺带补头像**：装一部剧情时把里面出现的角色、NPC、敌人的官方头像一起补上，不用再手动点「补全」。
- **老版本的错头像自动修**：升级后启动时清一次历史错图（别人的脸、活动宣传图）；官方本来就没给头像的角色保持无头像。

**修复与优化**
- 全屏后鼠标一直不消失，现在画面和工具栏上的鼠标都会自动隐藏。
- 侧栏悬停时同时冒出浏览器白气泡和详情卡两个浮窗。
- 双背景的左右两半挤在左半边，只看得见右边那张。
- 状态文案把「无语音」写成「缺公共素材」，漫画剧情被标成占位符。
- 主线 / 活动 / 其他也能排序了，默认最新的在最上面；没有官方顺序的活动不会再插到错的位置。
- 官方上新章节时列表显示「主线 第N章」，不再是「第 null 话」；对句标题（包む夢、抗う鼓動）能完整显示。
- 「活动剧情 第99话」「其他剧情 第80话」这种没名字、没归类的行会自己补好。
- 启动窗口不再打印剧情目录的统计行（只写进日志文件）。

### v1.1.9（2026-11-20）

**新增**
- **立绘可以打包带走了**：立绘页新增「导出立绘」。左侧点了角色就只导这个角色，没点就导当前范围的全部；「只看已下载 / 只看已收藏」和搜索框都生效。打包成 zip，优先高清图，按「角色名、服装」分好文件夹。
- **角色音声也能导出了**：原声集以前只能导 165 首原声，现在展开角色、勾选语音就能打包 m4a（按角色分文件夹）。新增「全选本角色 / 全选已展开」，点一下勾上这些角色的全部语音，再点取消；点「已选 N 项」可一次清空。一段都没勾时会问要不要导出当前列表的全部。
- **文本框能调宽窄和位置了**：宽度 40%–100%（默认 60%）、水平位置 0% 贴左 / 50% 居中 / 100% 贴右，也可以停在 80% 这种「靠右但不贴死」的位置；高度、离底距离也都能改。滑块拖到头只会贴住画面边缘，长句把框顶高时会自动收住，不会跑出画面。
- **新增「文字水平位置」**：调文字离框左边的距离，用来把正文推到头像右边；改的是框内缩进，不会把字挤出边框。
- **头像默认显示，放在对话框左上角**：默认 96px，名字条默认往右让 30px、正文默认往右让 14px，不再互相挡。选「对话框四角」时头像中心对准框角，「与名字间距」会自动置灰（框角模式跟名条无关）。老设置不会被硬改成新默认，想换就去设置页点「恢复本页默认设置」。
- **设置面板更好调了**：文本框页分成「外观 / 文字 / 大小与位置」，话者页分成「话者名条 / 角色头像」；在这两页拖滑块或切下拉时，面板临时变淡，能直接看到画面变化，松手就恢复。新增的选项都配了「?」说明。
- **键位少绑一格看得出来了**：某个键被挪到别的动作后，原来的位置留一个虚线空格，点一下就能补绑（「未设置，点击绑定」），不再出现「下一句只剩回车」却看不出少了什么。
- **立绘页「其他立绘」更干净**：官方还没公布为角色的编号（如 #364、#399）归到「其他立绘」，不再混在角色列表里；等官方公布后角色表一更新，她会自动回到角色列表，不用重装素材。

**修复与优化**
- **话者头像顶着别人的脸**：以前只看这张 CG 归属谁，第 5 段里男主的台词会顶着女主角的头像。现在名字对不上就不显示头像，宁缺勿错。
- **「全部立绘」显示已就绪却整组缺图**：以前只看源包下齐没有，合成失败也照样盖章。现在按「每套服装是否真的合成过」逐套对账，缺多少会写出来，点「补全」只补没合成的那几套；一批里某个包出错连累后面几十套不写、包里没有表情图层的素材整组消失，也一并修好。老用户升级后第一次只提示「需要点一次补全核对」，不会直接报几千套缺失。
- **导出跟着筛选走**：CG / 立绘开着「只看已收藏 / 只看未下载」或搜索筛过之后点导出，以前仍打包全量，现在只导当前看得见的那些，确认框里也会写明。立绘页左侧和卡片墙改用同一套筛选；从链接切到另一范围时会清掉上次选中的角色，不再显示空的「这里还没有素材」。
- **原声集三种排序都有效了**：「按实装顺序」改为按角色实装日期从新到旧（刚实装的排最前，老角色沉底），「按时长」「按曲名」也真正生效；音声模式下排序项显示「按实装顺序」，曲目模式仍是「按收录顺序」。
- **展开角色不闪、不跳**：以前点一个角色展开会重画两百多个分组，整列闪一下、滚动位置乱跳，现在只插入或摘掉这一组的行。
- **分享图「用播放器样式」所见即所得**：修好了文字换行被合并、正文水平位置不对、名条整体偏上近一个名条高、头像画框底色和外扩跟画面不一致；当前句的头像直接复用屏幕上那张，其他句按剧本原名解析，避免画出别人的头像。
- **唱片中心那个圆点去掉了**：音声模式中心贴的是角色头像 / 立绘，圆点压在上面不搭。
- **手机上的对话框宽度**：不再被手机样式强行覆盖，跟电脑一样按设置里的宽度和位置显示。

### v1.1.8（2026-11-18）

**新增**
- **数据更新后列表自己变新**：装完素材或更新程序后，剧情、CG、立绘、原声的列表会自动刷新，不用再手动按 F5；真有新增内容只提醒一次，不反复催。
- **启动窗口只留启动说明**：运行日志改写到日志文件，窗口不再刷屏；出错时仍能看到程序装在哪、用的是哪个 Python。

**修复与优化**
- **下载卡住却一直显示有速度**：控制台窗口被选中会让程序卡在打印上，下载跟着停住。现在日志不再往窗口打，下载改成边下边存、断开能接着下；真卡住时任务条显示「等响应 N 秒」，不再拿旧速度骗人。
- **切一次页面卡两三秒**：页面状态改成本地缓存，来回切页几乎立刻响应。
- **更新检查反复跑**：只在启动时查一次新版本，不再每分钟偷偷查；开始更新 / 更新完成会提示先关掉其他旧窗口。
- **升级后白问一次「修复立绘」**：只有本机立绘确实是旧办法合成的才提示；1.1.6 → 1.1.7 这种没动合成逻辑的升级不再打扰。
- **新角色的稀有度 / 实装日期还是旧值**：以前按名字配对，漏掉当天新加的角色；现在按编号补齐。
- **素材补全误报「缺一千多张」**：头像、横幅明明全齐还报缺口；现在按占比判断，只补真正缺的那几个包。
- **任务条看不清进度**：标题太长把「下载占 60%、剩下是解包」挤没了，分段线太淡 —— 现在都改清楚了；「详情」不再红得像报错。
- **播放器小毛病**：只有真的移动鼠标才算手势；工具栏已有「退出」时不再多一个 ✕。

### v1.1.7（2026-11-17）

**新增**
- **播放页显示「角色头像」**：名条旁边画出当前说话人的头像，自动按剧情里出场的那张立绘匹配

  「恢复本页默认设置」。话者名条现在能单独调水平 / 垂直位置。
- **全站悬停说明换成 14px 自绘气泡**：浏览器原生的只有 12px，比正文还小；需要解释的地方带
  「?」角标，鼠标停一下才出现，扫过列表不会刷屏。
- **资源管理页新增「全部立绘（含剧情里没用到的）」**：官方是「一套服装一个包」，剧本只用其中
  几张，同一套里别的表情永远不会出现在剧情里。这一项把缺的补上（下过的不重下）。
- **原声集分类按钮默认收起成一行**：点一下才展开全部分类，选完自动收起。

**修复与优化**
- **页面更快、也不再重下同样的图**：以前禁止一切缓存，刷新一次要重取 385 张头像和横幅
  （约 6.7 MB）。现在图片按内容指纹长期缓存，页面 / 脚本 / 样式也自动换版本 ——
  「改了代码却忘了升版本号、看到的还是旧页面」不会再发生。
- **列表滚到哪取到哪**：打开页面只取 9 张（原来 385 张全取），窄屏抽屉收起时一张都不取。
- **升级后打不开页面（404）**：更新包以前只放行几个写死的页面文件名，新版新增的页面在升级时
  被挡在门外；现在按规则放行，启动时还会自查缺不缺文件。
- **「全部立绘」的进度条**：下载和合成各占一段，取消 / 失败不再显示「已就绪」，下次接着补。
- **「补全」头像白下 102 个包**：那批官方编号必然拿不到图，还会被算成「导出失败」；不再下载、
  也不再报错。
- **素材换了还是旧图**：只有版本号与当前素材完全一致的图才长期缓存，其余先校验（没变回 304）。
- **同一首歌两路一起响**：现在只有一路能拿到「播放权」，切多少次页都只有一份声音。
- **设置面板里的文字挤成一堆**（「位置 名条左侧 名条右侧 …」重复一大段、数值出现两个）：
  界面文案表缺新条目时，会把下拉框里的选项文字也当成标题写回去。现在只替换标题本身，
  下拉框 / 数值一律不动；更新包里也带上了最新的界面文案。
- **手机上「点不到、进去出不来」**：原声集控制条被挤出屏幕、歌单一开就关不掉（现在「☰ 列表」+
  左侧滑出歌单，✕ / 点空白 / 选完都会收起）；唱片模式在手机上几乎没变化（现在顶栏收起、唱片
  铺满）；跨页播放设置从 300px 小窗改成底部整屏面板；立绘卡片按「一屏几张」算；横屏顶栏压住
  标题；剧情页窄屏 GitHub 图标被挤到第二行（那排控件改成可横向滑动，两端有「‹ ›」提示）。
- **手机上展开的浮层收不回去**：跨页播放浮窗、角色音声的分组详情、设置面板的说明气泡、
  CG / 立绘抽屉都补了「点外面就收起」；抽屉还补了遮罩和「✕ 收起」。
- **原声集的小毛病**：收藏键改回红心、点一下不再变大变小；播放 / 暂停图标真正居中。
- **点「直接开始」后刷新又弹新手引导**、**提示条固定 3.2 秒读不完**（现在按字数，最长 12 秒）、
  **离开电脑时跑完的任务回来什么都看不到**（改按页面可见时长计）、
  **「检查并修复立绘」的结论只停 15 秒**（现在留在页面上）：都已修好。

## 第一次用

1. 解压 portable 包到一个**路径里没有中文和空格**的目录，双击 `启动.bat`
2. 打开「资源管理」页 → 下载**基础数据**（资源清单 + 公共素材）
3. 再到「剧情安装」勾想看的角色，点「开始安装」
4. 装完回「角色剧情」页，点角色就能播
