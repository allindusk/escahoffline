# 超昂大战 · 离线剧情阅读器（ESCAH Offline）

把《エスカレーションヒロインズ / 超昂大战》的剧情，做成能在浏览器里**离线翻阅的电子书**：
背景、立绘、CG、语音、音乐按原作脚本重新播放，也能把某段剧情录成视频、把 CG 打包带走。
中文译文不随程序附带，愿意翻的话可以把原文导出给 AI 或自己翻，再导回来。

一个本地网页程序：双击启动 → 浏览器打开 → 装想看的剧情 → 看。
Windows 有开箱即用的便携包，macOS / Linux 可以用源码跑。

## 有什么

### 看剧情

- **还原原作演出**：背景、立绘（含表情差分）、CG、语音、BGM、画面特效，按剧本指令逐条重放
- **中日切换**：界面和剧情都能切语言（顶栏按钮或按 `L`）；导入译文后显示中文，没翻到的句子显示日文原文，不会留空白
- **四种剧情**：
  - **角色个人剧情** —— 每个角色的个人故事，可按名字搜、按稀有度 / 实装日期排
  - **主线** —— 主线故事，按部 / 章排列
  - **活动** —— 期间限定活动剧情，按上线时间排
  - **其他** —— RAID BOSS、広域戦、殲滅戦、記念イベント、エイプリルフール、Hシーン集、投票，按游戏入口分组
- **跟得上更新**：游戏上新以后刷新一次剧情目录，最新剧情就能装，不用等程序发新版
- **知道还差什么**：侧栏能筛「只看未下载」，没装的直接标着「未下载」；切到中文后标题栏显示这部翻了多少
- **手机上也能看**：点右上角「局域网二维码」，手机连同一个 WiFi 扫码就能看
- **顺手**：空格暂停、回车下一句、按住 K 快进、F 全屏；播放控制条最右的 `?` 列出全部快捷键

### 看 CG

「角色 CG」页是图库：角色 / 主线 / 活动 / 其他四类分开，能搜、能按日期排、能只看已下载，
也能收藏、能调卡片大小；点一张开大图，可左右翻页、可全屏。页面上方的「⬇ 导出 CG」
能把当前角色（或整部剧情）的 CG 打包成 zip。

### 工具箱（「资源管理」页）

- **装剧情**：勾一部，点「开始安装」，语音 / 立绘 / CG 自动一起下好
- **提高画质**：把已装的图放大成高清版（Real-CUGAN 引擎，便携包自带）；原图不动，随时能反悔；
  动手前可以先「查看效果」，左右拖动对比
- **导出视频**：把一部**角色剧情**合成 1080p mp4，勾多段会连成一条（主线 / 活动暂不支持）
- **翻译**：把剧情原文导出成 zip 丢给 AI，翻好用 txt / 文件夹 / zip 批量导回，程序自动认是哪部
- **更新 / 清理空间**：剧情目录更新、程序自我更新；占地方的东西按用途列全，告诉你哪些删了不影响看

## 三步上手

### 1) 拿到程序

去 [Releases](https://github.com/allindusk/escahoffline/releases) 下载
`ESCAH-Offline-v*-win64-portable.zip`，**完整解压**到一个文件夹（路径里尽量别有中文和空格），
双击里面的 **`启动.bat`**。

黑色窗口会弹出来，**别关**（关了网页就用不了），浏览器自动打开播放器页。
不用装 Python、不用装任何依赖。

> 会用命令行 / 想改代码：clone 仓库后 `pip install -r requirements.txt`，
> 再 `python -m server --open`。系统和依赖要求见[技术细节](docs/技术细节.md)。

### 2) 装剧情

**第一次打开时侧栏全是灰的、一部都放不了，这是正常的**——素材还没下到本机。

1. 点顶部导航进 **「资源管理」**
2. 「① 概览 / 快速开始」→ 点 **「下载基础数据」**（剧情目录 + 公共素材一次下齐，界面会显示要下多大）
3. 「② 剧情安装」→ 勾一部想看的（能按名字搜、按分类缩），点 **「开始安装」**
4. 一部剧情装下来通常一两分钟以内；全部装完是很占硬盘的量，所以随时可以分批装，装过的不会重复下

### 3) 看

回「角色剧情」页，点左边角色就开播。第一次进可以先点导航栏的 **「?」** 走一遍新手引导（按 `H` 也行）。

## 关于联网

- **看剧情完全离线**，断网也能看，本地不跑任何上传
- 只有三件事会联网：
  - **装资源 / 更新剧情目录**（连官方服务器）
  - **检查程序更新**（连 GitHub，可在设置里关掉）
  - **更新角色信息**（**手动点击**才联网，从 GitHub / Wiki 拉取）
- **客户端不做任何后台轮询**：不会定时检查角色资料、不会定时检查更新。角色资料由项目的 CI
  （GitHub Actions）每天生成并随仓库 / 发布包提供，**客户端只在你主动点按钮时才会去拉**；
  连不上不影响看剧情
- 不收集、不上报任何使用数据

## 常见问题

<details><summary>点角色提示「资源还没有下载」</summary>

那部剧情还没装。去「② 剧情安装」勾上它，点「开始安装」；装好会自动出现在播放器侧栏。
</details>

<details><summary>有画面但没声音</summary>

一是没装「公共素材」里的音乐 / 音效；二是浏览器拦了自动播放——点一下画面再播。
</details>

<details><summary>立绘缺脸 / 显示不完整</summary>

约一成特殊立绘在游戏里本身就是分层图，本来就没有完整底图。打开设置勾「显示不完整立绘」能看底图。
</details>

<details><summary>下载很慢 / 反复失败</summary>

把「同时下几个」调小（默认 32，网差就试 8 或 16）。安装支持断点续传，中断后重试会接着下，
已经下完的部分不会重来。
</details>

<details><summary>导出的视频里没有震屏、闪光？</summary>

导出是逐句拍图再拼成视频的，所以「动」的效果在视频里是静止的（位置和画面都对）。
想体验完整演出节奏请用播放器。
</details>

<details><summary>更新会不会把译文和设置弄丢</summary>

不会。更新只替换程序文件，素材、译文、设置都在保护名单里。不过升级前自己备份一份
`userdata/` 总是好习惯。
</details>

更多步骤和排错见[用户手册](docs/用户手册.md)，页面里「⑧ 帮助 / 教程」也有一份可折叠的问答。

## 游戏更新了怎么办

剧情目录是随时可刷新的，不用换程序：

- 官方上新后，到「⑥ 更新」→ 点 **「更新剧情目录」**（建议等开服一小时后再点），
  新剧情就会出现在「② 剧情安装」里；新角色的头像、剧情横幅缺了会自动补上
- 程序本身有新版时，「⑥ 更新」页顶部会提示，点「下载并应用」即可，你的数据都保留
