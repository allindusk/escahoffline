# 词汇表（Glossary）

剧情翻译的统一译名。**改一处，全站一致** —— 避免同一个人物/术语在不同剧情里
出现好几种叫法。

程序导出译文 txt 时，会把**本目录在你电脑上的完整路径**写进提示词，
让 AI 先读这里再动手翻译。

## 目录里有什么

| 文件 | 内容 |
|---|---|
| `characters.yaml` | 角色名**结构化**词表：`base`（形态基名）/ `prefix`（形态前缀）/ `suffix`（形态后缀）/ `alias`（拼不出来的整名例外）。同一基名的所有形态共享一个中文译名 |
| `names.yaml` | 专有名词精译：角色 / NPC / 支援者 / 道具 / 装备 / BOSS 等 |
| `terms.yaml` | 剧情术语（日 → 中），按"是否出现在剧情原文"精简过 |
| `phrases.yaml` | 常用句/固定说法 |
| `phrases_manual.yaml` | 手工补的句子（优先级低于自动筛选） |
| `high_freq.yaml` | 高频词（大表，命中率最高） |
| `r18.yaml` | 成人向用语（按需参考） |
| `characters_generated.yaml` | 由 `characters.yaml` 自动展开的形态表，**不要手改** |

## 格式

基本都是 YAML 的 `日文: 中文` 映射，例如：

```yaml
神騎プラチネル: 神骑普拉奇内尔
幻魔: 幻魔
```

`characters.yaml` 是结构化的（`base` / `prefix` / `suffix` / `alias` 四段），
加新角色时按里面已有的写法补。

## 注意

- 这是**本机的词汇表**：程序更新**不会覆盖**它（纯代码更新包里不含此目录），
  可以放心长期维护。
- 译名不要求"官方"，只要**全篇一致** —— 一致性比准确性更影响阅读体验。
- 也可以自己新建 `.csv` / `.md` 放进来，导出时整目录路径都会给到 AI。
