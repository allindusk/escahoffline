## 这是什么

把《超昂大战》的角色个人剧情做成**可以离线翻阅的电子书**：

- 还原原作演出：背景 / 立绘 / CG / 语音 / BGM / 特效动画，按原作脚本指令逐条重放
- 带中文译文（可导入导出，最适合丢给 AI 翻译）
- 可以把某段剧情**录成视频**，把角色 CG **打包导出**
- 纯本地运行，不联外网，不上报任何数据
- 便携：解压即用，素材与程序分离，程序更新不碰你的数据

**它不是游戏**：没有战斗、没有养成、没有抽卡。只是一个剧情浏览器。

## 三步上手

### 1) 拿到程序

两种方式，选一个：

| 方式 | 适合 | 说明 |
|---|---|---|
| **下载 Release 里的全量包** | 大部分人 | `*-win64-portable.zip` 内置 Python + Pillow，解压后双击 `启动.bat` 即可，不用装任何东西 |
| **git clone 源码** | 想改代码 / 非 Windows | 需要 Python 3.8+，`pip install -r requirements.txt`（只装 Pillow） |

> **国内下载慢？** GitHub Release 落到 `objects.githubusercontent.com`，实测本机直连
> 只有 **0.7 MB/s**（而且还时不时握手失败），套一层反代能快一个数量级 ——
> 2026-10-30 用本项目自己的包实测（4 线程，取 4 轮中位）：
>
> | 线路 | portable 包 114 MB |
> |---|---|
> | `https://gh-proxy.com/` + 原链接 | **22.6 MB/s** |
> | `https://git.yylx.win/` + 原链接 | 18.7 MB/s |
> | `https://edgeone.gh-proxy.org/` + 原链接 | 16.6 MB/s |
>
> 把原链接**整个粘在斜杠后面**就行，例如：
> `https://gh-proxy.com/https://github.com/allindusk/escahoffline/releases/download/v1.0.0/ESCAH-Offline-v1.0.0-win64-portable.zip`
>
> 三条快线下出来的 zip **sha256 与官方一致**。程序不会自己偷偷联网检查更新 ——
> 想更新就在控制台点「检查程序更新」，看到有新版本再点「下载并应用」，装完会自动重启并提示刷新页面。
> 便携包的下载地址记在 [`docs/资源包与发布.md`](docs/资源包与发布.md)。

```bash
git clone https://github.com/<你的名字>/escalation-heroines-offline.git
cd escalation-heroines-offline
pip install -r requirements.txt   # 必须：UnityPy / lz4 / Pillow / numpy（解包要用）
python -m server --open           # Windows 也可以直接双击 启动.bat
```

> 依赖不再是"可选美化"：资源从官方 CDN 拉的是 **Unity AssetBundle**，
> 没有 UnityPy + lz4 就解不开、没有 numpy 就合不了立绘。便携版已经内置这些，
> 源码方式请务必装全。
>
> 嫌 pip 慢？直接双击 `启动.bat`：它发现缺依赖时会调用
> `tools/bootstrap_deps.py`，**先实测清华/阿里/腾讯/华为/中科大等镜像的速度，
> 选最快的那条再下**（实测同一时刻 PyPI 官方只有 288 KB/s，华为云 11.9 MB/s）。
> 也可以手动： `python tools/bootstrap_deps.py --test` 只看测速结果。

浏览器会打开 <http://127.0.0.1:8000/setup.html>（资源管理页）。

> **项目里有两个「启动」脚本，别点错：**
>
> | 脚本 | 用途 | 端口 |
> |---|---|---|
> | **根目录 `启动.bat`** | 正常使用（含完整后端：安装剧情、检查更新、导出） | 8000 |
> | `web/dev-preview.bat` | **只有开发才用**：纯静态预览，看 HTML/CSS 改动。没有后端，安装/更新都会失败 | 8100 |
>
> 发布包里**只有根目录那个**，`web/` 下的是调试工具，不会打进去。

### 2) 装资源（不用准备任何文件，勾一下就行）

**项目里没有素材，第一次打开时一部剧情都放不了，这是正常的。**

到「资源管理 → 剧情安装」，勾一个角色，点「开始安装」：

- 安装器会**直接从官方 CDN 拉取资源包**（Unity AssetBundle），在本机解包成
  播放器能用的图片 / 语音 / 剧本，并自动合成立绘的表情差分
- 单部角色剧情约 **30–60 MB**，装一部 **30–90 秒**
- 全部 611 部约 20 GB，可以随时分批装；装过的不会重复下

> **为什么仓库里不放素材？** 20 GB + 版权。程序只带索引（目录树、图片映射、清单种子），
> 素材每次按需下载解包。下载地址在源码里是**加密存放**的
> （[`web/data/packs.links.js`](web/data/packs.links.js)，RC4+base64），运行时才解密；
> 官方域名若变更，用户可在「设置 → 下载源」自行覆盖，不用改代码、不用重新打包。

### 3) 看剧情

回「角色剧情」页，左侧点角色即可。顶部「?」是新手引导，一步步告诉你每个按钮干什么。

## 功能一览

### 资源管理（`setup.html`）

- **剧情安装**：按角色 / 主线活动分类，搜索、勾选即装。装的是"一部剧情"而不是资源包，
  它的语音、背景、立绘、CG 会自动一起下好并解包
- **并发可调**：8 / 16 / 32 / 64，附实测速度对照与"该选多少"的说明
- **清单刷新**：官方上新后同步清单（AES 解密），告诉你新增了哪些剧情
- **画质处理**：可选超分（内置 Lanczos+锐化，或外置 Real-ESRGAN）、批量转 WebP、
  一键删已超分原图。超分产生**新文件**不动原图，所以备份天然存在
- **进度可视**：百分比 / 速度 / 剩余时间 / 已完成包数，可取消；关掉页面任务照样跑

### 播放器（`index.html`）

- 分层立绘合成、双背景、CG、BGM/SE/语音、自动演出与打字机效果
- 多语言 UI + 剧情译文（中日对照，运行中切换语言）
- 显示设置：字号/行距/描边/对话框样式/立绘高度与偏移/音量/打字速度/倍速/适配缩放
- **未下载标记**：没装资源的剧情在侧栏排到最后并标红「未下载」，点它会引导去下载
- **录制**：控制条「⏺ 录制」把当前段从头播一遍并录成 `.webm`
- **译文面板**：导出块式对照 txt（一句一个 `###` 块，带编号/说话人/行数）→ 交给 AI → 导回即生效；
  发言人名字另走全站共用的 `_speakers.json`，翻一次所有剧情通用

### 导出

- **剧情视频**：单段多段、单角色多角色（在「导出」页生成队列，播放器里一键开始，
  自动逐段录完）。录制是浏览器内实时翻录，耗时≈剧情时长
- **角色 CG**：按角色/事件组打包 zip，只导一个有 CG 的角色也很快
- **译文**：导出/导入 txt

### 更新

- **资源更新**：拉新 `packs.json`，发现新剧情 → 引导下载
- **程序更新**：检查 GitHub Release → 下载到暂存区 → **退出后替换程序文件** → 自动重启。
  只覆盖 `server/` `web/assets/` 等程序白名单，**你的素材、译文、设置一个都不会丢**。
  这套方案和 qBittorrent、PortableGit 的更新机制同理。

## 安装一部剧情时，到底发生了什么

没有"预处理好的资源包"这种东西，全部在本机现做：

| 步骤 | 说明 |
|---|---|
| ① 资源清单 | 拉官方的 `Manifest1Ex` / `Manifest2Ex`（AES-256-CBC 加密，25,204 个 bundle 的 size / hash / 依赖图）。**清单不随程序附带**——它随官方更新变化，附带只会给你过期数据；首次会提示下载（约 5 MB，有进度），官方上新后再点「刷新清单」 |
| ② 算依赖 | 按命名规则反查这部剧需要哪些 bundle：剧本 1 个 + 语音按段 + 背景/立绘/CG 按剧本实际引用 |
| ③ 并发下载 | 默认 32 连接。官方 CDN 单连接只有 60–100 KB/s，瓶颈是每条连接的吞吐与 TLS 握手，并发是唯一有效手段（实测 32 并发 ≈ 7.7 MB/s） |
| ④ 解包 | UnityPy 读出 Sprite / AudioClip / TextAsset → WebP / m4a / 剧本 JSON |
| ⑤ 立绘合成 | 游戏里的立绘是「底图（脸挖空）+ 表情差分层」，落点靠 numpy 做全位移 SSD 匹配算出来，与官方显示一致 |
| ⑥ 应用 | 写出 `web/data/char_<id>.js` 与 `web/media/...`，并刷新索引映射 |

所以"装一部剧情"= 下载 + 解包 + 合成，全程本地完成，**不需要你另外准备任何分发包**。

> 旧版本曾提供"自己打 zip 资源包"的模式（`tools/build_packs.py` + `tools/make_pack_archives.py`），
> 在改用官方 CDN 直连后已不是主路径，脚本保留但不再需要运行。

## 目录结构

```
escahoffline/
├─ 启动.bat / start.sh     启动脚本（等价于 python -m server --open）
├─ server/                 本地服务端（下载/解包/超分/导出/更新 API）
├─ web/                    站点（播放器 / CG 画廊 / 控制台）
│   ├─ data/               索引（进 Git）+ 剧情正文（资源包分发，不进 Git）
│   └─ media/              素材（永不进 Git）
├─ tools/                  维护脚本：build_packs / build_imgmaps / make_pack_archives / encrypt_links
├─ docs/                   文档
└─ userdata/               你的数据：config / state / 下载缓存 / 备份 / 导出 / 日志
```

## 常见问题

<details><summary>点角色提示「资源还没有下载」</summary>

该角色的资源包没装。去「资源管理 → 资源包下载 → 按角色智能勾选」，输入角色 ID，
它会自动带上核心包和公共素材。
</details>

<details><summary>有画面但没声音</summary>

1) 没装「公共音乐音效」包；2) 浏览器拦截了自动播放 —— 点一下画面再播。
</details>

<details><summary>立绘缺脸 / 显示不完整</summary>

约 10% 的特殊立绘在原作里本身就是分层图。播放器设置里勾「显示不完整立绘」可看底图。
</details>

<details><summary>下载很慢 / 反复失败</summary>

线程数调到 1–2；确认直链没过期（网盘直链常有有效期）；检查磁盘空间。
安装器支持断点续传，中断后重试会接着下。
</details>

<details><summary>能局域网给手机/平板看吗</summary>

`python -m server --host 0.0.0.0`，手机访问 `http://电脑IP:8000`。
注意这样同网段的人也能访问管理接口，只在可信网络下这么做。
</details>

<details><summary>更新会不会把我的译文/设置弄丢</summary>

不会。更新只替换程序白名单里的文件；`web/media`、`web/data`、`userdata`
都在保护名单里。但**升级前建议自己备份一份 `userdata/`**，任何工具都该这么用。
</details>

<details><summary>为什么不做成 Windows 桌面应用 / 不用 Electron</summary>

不必要。文件读写、多线程下载、图片转码这些活 Python 标准库就够，浏览器负责渲染，
本地 HTTP 服务把两者接起来。这样体积小（便携包 ~30 MB）、跨平台、还能直接用浏览器
DevTools 调试。桌面壳套一层只会增加分发与杀软误报的麻烦。
</details>
